# Top 8 任务脚本（v3.5.0 冻结）

| 项 | 内容 |
|---|---|
| 状态 | **冻结**（2026-11-09）。之后每版用同一脚本复测，**禁止改脚本来优化数字** |
| 样本 | 8 名内部用户（D4 裁定），独立完成、不求助 |
| 计时点 | 从「读完任务描述」开始，到「达成成功判据」为止；失败/求助均记失败并保留耗时 |
| 步数定义 | 一次点击、一次输入提交、一次页面跳转各计 1 步；键盘快捷键计 1 步 |
| 证据 | 每人一份原始计时表 + 录屏/记录 + 汇总报告；**真人样本未到位前本脚本只作冻结件，不产生读数** |

## 脚本

| 任务 | 名称 | 动作序列 | 成功判据 | 参考步数 |
|---|---|---|---|---|
| T1 | 建项目并配置内核 / 资产 | 进入项目列表 → 新建项目 → 选择 RF 或 pytest 内核 → 保存 → 关联资产/环境 | 项目出现在列表且内核字段与选择一致；可重新打开查看 | 5 |
| T2 | 导入或编辑用例并保存 | 打开用例页 → 新建用例 → 填写名称与步骤 → 保存 → 刷新列表确认 | 用例可检索到，正文与保存前一致；草稿不丢 | 6 |
| T3 | 从台账挑用例发起运行 | 进入台账 → 勾选用例 → 加入运行 → 选择内核与环境 → 确认发起 | 生成 RUN_ID，运行页出现该运行且状态非终态错误 | 6 |
| T4 | 运行中查看进度 / 日志 / ETA | 打开运行详情 → 查看进度条 → 展开实时日志 → 查看 ETA | 进度、日志、ETA 三处均有真实数据且随运行更新 | 4 |
| T5 | 定位失败用例与证据 | 运行结束 → 打开结果 → 筛选失败 → 打开单条证据 → 查看日志/截图 | 能指出失败用例 ID 与证据文件路径，跳过数显示正确 | 5 |
| T6 | 生成并导出报告（内 / 外两种口径） | 报告页 → 生成报告 → 选择内部口径导出 → 再选对外口径导出 | 两份产物均可下载；对外字段白名单生效；metadata 十项齐全 | 6 |
| T7 | 用搜索 / 保存视图找回历史运行 | 全局搜索输入历史运行 ID → 打开结果 → 或载入已保存视图 → 确认筛选条件保持 | 目标运行可被找回；保存视图刷新与重登后条件不丢 | 5 |
| T8 | 管理员处理归档 / 节点 / 告警 | 进入运维中心 → 查看节点心跳 → 查看告警规则 → 查看归档策略（默认停用） | 三处状态可读；归档未被擅自开启；告警通道状态可见 | 5 |

## 冻结纪律

1. 脚本、数据集、环境、样本量写进证据；任何变更须升版本并留修订记录。
2. v3.6.0 复测必须用**同一脚本、同数据集、同环境**，否则降幅判据无效。
3. 无真人样本时，度量字典对应项写「未测量」，测试报告记 `BLOCKED`，**不得用机器指标替代**。
