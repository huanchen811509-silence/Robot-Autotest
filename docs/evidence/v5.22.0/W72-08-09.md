## 2 06-4 的降级与顺带修的缺陷

## 4 门禁 64 抓出的越权（口径修正）

首轮全量门禁 `FAILS=2`，其中一条是 64 role_surface：

```
FAIL  viewer    用例集    写按钮 1   导入用例
```

W72-08 新增的空态「导入用例」没加 `case:write` 守卫。导入本身写用例集，viewer 进去也提交不了，
给入口等于给一个必然失败的按钮。修 `2bd72ff`：与「新建」同口径隐藏，只留只读的「查看样例」。

修后重跑：

```
PASS  admin     用例集    写按钮 3   新建用例集 / 新建用例集 / 导入用例
PASS  engineer  用例集    写按钮 3   新建用例集 / 新建用例集 / 导入用例

[role-buttons] 9 组，FAILS=0
[role-buttons][self-test][PASS] 注入后判红（viewer 用例库写按钮 1 个）
```

对照组（admin / engineer 仍 3 个）没被削弱，说明探针判据仍然有效，不是把阈值调松换来的绿。
