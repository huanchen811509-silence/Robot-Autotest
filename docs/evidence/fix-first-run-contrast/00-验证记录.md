# 项目卡片「发起运行」撞色与字数优化 —— 验证记录（2026-11-17）

> 来源：大师用户视角反馈「项目总览卡片里『发起第一次运行』字体和按钮颜色一致看不清，且字数太多」。
> 归属：v5.22.0 / FR-v5.22-06 判据 06-3 引入的 CTA 缺陷修复（v5.23 已落号，本修复未并入，待发版）。
> 证据形态：CDP 黑盒实测 computed style + 截图 + WCAG 对比度计算 + 全量单测。

## 1 根因（CDP 实测，rgb 值直接读自浏览器）

| 项 | 修复前 | 修复后 |
|---|---|---|
| 按钮文字 | 发起第一次运行（7 字） | 发起运行（4 字，-43%） |
| `color` | `rgb(251,146,60)` | `rgb(251,146,60)` |
| `background-color` | `rgb(251,146,60)` ← 与字同色 | `rgba(0,0,0,0)` 透明（描边） |
| `border-color` | `rgb(251,146,60)` | `rgb(251,146,60)` |
| 按钮宽 × 高 | 91 × 52 px（文字折两行） | 82 × 33 px（单行） |

**根因**：全局 `.btn`（`main.css:209`）是实心主色按钮（`background: var(--accent)`）；
`.btn-first-run` 只覆盖了 `color`/`border-color` 为 `--accent`，**漏改 background**，
导致字色 = 底色 = `--accent`（当前橙色主题 `rgb(251,146,60)`）。各种主题色下均复现。

## 2 WCAG 对比度

| 场景 | 对比度 | 结论 |
|---|---|---|
| 修复前 字=底（同色） | **1.00:1** | 完全不可读 |
| 修复后 深色 橙字 `#fb923c` on 卡片底 `#1a2634` | **6.77:1** | 超 AA 正文 4.5:1 |
| 修复后 浅色 蓝字 `#1567c9` on 卡片底 `#ffffff` | **5.50:1** | 超 AA 正文 4.5:1 |
