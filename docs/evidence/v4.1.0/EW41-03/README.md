## 2. 实现口径

- **预检与导入同源**：预检只读、不写库，返回可导入结论与可疑项清单；
- **幂等**：以稳定业务键比对，重复导入全部 `SKIP`，不产生重复行；
- **冲突策略**：`SKIP / OVERWRITE / RENAME` 三档由请求体选择，默认 `SKIP`；
- **隔离区**：可疑脚本先落 `.quarantine/<code>/<job>/`，必须显式确认勾选后才写库并逐条留 `warning`；
- **事务**：写入 1 行即成功提交；失败任务保留 `FAILED` 状态与原因，不半途留脏数据。
