## 3. 与 PRD 分区方案的差异

| PRD 写的 | 实际 | 原因 |
|---|---|---|
| 行内只留「详情」，编辑/暂停/触发/删除进「更多」 | 行内只留 1 个「更多」，四动作全在菜单里 | PRD 同节判据写「DOM 控件计数 ≤ 8（首屏）**+ 行内 1**」；「详情 + 更多」是行内 2，与判据冲突。按判据执行；且计划本没有独立详情页，硬造一个入口只会多一次点击 |
| 新建 / 编辑改为侧边抽屉或独立页 | 仍是页内表单卡 | 判据未涉及；改抽屉会把表单搬进 teleport，`.form-card` 的三条既有用例全要重写。已记入 `DEV-PLAN.md` 偏差，排 v3.10.1 与「更多」菜单的键盘可达性一起做 |
