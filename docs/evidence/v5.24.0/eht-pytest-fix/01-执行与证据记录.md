## 5. 关键发现（回写评估/契约）

1. **junit 有 `[明细]`**：平台 `--capture=fd` 生效，无需改读 framework.log（推翻旧推断）。
2. **`PytestCriteriaExtractor` 只读 system-out 漏掉 9/10 用例**：logging 写 stderr，已补读 system-err。
3. **`criteria_json` 是结构化快照不是原文**：Plan-only 无 `[判定]` → 空 + MISSING 是**诚实**行为，不是 bug；real 有 `[判定]` → 合成 JSON → PASS/FAIL。
4. **real 选错设备**：project 95 有 2 台 `eht-fake-host@127.0.0.1/2` 排在真实设备前，`case_target("first")` 选中 fake → SSH 连 127.0.0.1 失败。**用 `hostKeys` 过滤真实设备即通过**。平台默认不排除 fake 设备，是待补的产品缺陷（W-EHT-08/09）。
