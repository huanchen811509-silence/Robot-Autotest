## 2. 命令证据断链根因与修复

### 2.1 根因（诊断测试证实）

| 环节 | 事实 |
|---|---|
| 命令索引本身 | 能正确提取 `readlink -f /sys/class/net/ens17np0/device`（诊断测试 `has=true`） |
| 执行侧 | `PytestNicRunController:578` 补录只用于内存计数 |

| 定性 | 两条归一链路割裂；此前验收只断步骤/判据，未断命令列 |

- `PytestCommandEnricher` 新增 `enrich(Path, NormalizedRun, Map<scriptPath>)` 重载。
- `ReportIngestService` 注入 `PytestCommandEnricher` + `ProjectSettingRepository`，归一后从 `<repo>/artifacts/<run_id>/` 补录；二次归一只取脚本映射；任何异常跳过补录，不阻断报告。
- 设计契约：`docs/design/EHT-命令证据与删除契约.md`。
