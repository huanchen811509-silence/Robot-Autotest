# 六类韧性故障注入计划与判据（EW37-02）

| 项 | 内容 |
|---|---|
| 状态 | **PARTIAL**：计划与判据成文；低风险注入留证，高风险四类需维护窗口 |
| 四步铁律 | 备份 → 注入 → 定向判据**必须红** → 用备份拷贝还原 → 复跑绿；缺一不算验证 |
| 红线 | 执行状态机不得伪造完成；幂等键 0 重复运行；优雅停机审计不丢 |

| # | 注入 | 定向判据（须变红） | 本轮状态 |
|---|---|---|---|
| 1 | 超时 | 首字/完成超时，SSE 落库状态为超时而非成功 | 契约机检已有（门禁 24），未做服务级注入 |

| 4 | 磁盘满 | 写入失败有明确告警，不静默丢日志 | BLOCKED（同上，高风险） |

> 未执行的注入一律 `BLOCKED`，**不得写「通过」**；恢复后必须复跑 27 步门禁并留同批次汇总。
