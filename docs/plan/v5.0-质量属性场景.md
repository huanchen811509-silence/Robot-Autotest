## 1. `Safety` 排除理由（D4 已裁定）

本产品是测试执行与报告平台，对被测设备**只读采集、不控制物理动作**，不承担人身、财产或环境安全相关的控制职能；
Safety 特性（系统在既定条件下不危及人身、财产或环境）在本产品的质量属性场景中无对应失效模式，
故本版不纳入，也不以「无相关风险」折算成 PASS。若后续版本引入设备写操作，须重新评估并新增场景。

## 3. 判定纪律

1. 每条场景必须绑定至少一个 FR 与一个 TC，由 `tools/check_v50_scenarios.py` 机检。
2. `SC-09` 依赖 CDP `:9222`，按 D1 保持取消，本版如实登记 `NOT-RUN`，不得由静态机检代判。
3. 实验室读数（lab）与真实用户读数（field）分开，lab 不得写成「达标」。
