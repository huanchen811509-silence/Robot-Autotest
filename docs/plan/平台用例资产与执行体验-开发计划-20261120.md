## 1. 通用约束

1. **白泽只读**：不修改 `new-baize` 任何文件、不复制其代码、不引入其 `package.json`/构建产物；参考处（`W84-04`）在文件头注明「设计参考 new-baize/...（只读），实现为本项目自研，差异点：配色/事件/取色」。
2. **构造器注入**：依赖一律构造器注入，一个类只能有一个公开构造器（`ArchitectureTest` R6 禁 `@Autowired` 字段注入）。
3. **迁移只追加**：不改历史迁移；每条迁移配 `db/down/` 回滚；迁移号从 `V11_85` 顺延。
4. **分页前过滤**：任何新筛选条件在 repository/SQL 层生效，禁止分页后内存过滤（否则 `total` 与结果不一致）。
5. **状态源唯一**：安全级、优先级、评审态、绑定四态各自只有一个产出函数；前后端不得各拼一套。
6. **i18n 双语同源**：新增键 `zh-CN` / `en-US` 同时加，`check_i18n.py` 必须 PASS；含 `@` 的串按既有转义写法。
7. **审计必写**：绑定确认、批量定级、置信度修改、节点删除/归档、备份删除、计划立即执行、知情确认，全部写审计。
8. **能力码**：新增写操作走 `case:write` / `execution:write` / `settings:write`，越权 403，后端兜底。
9. **迁移不随启动**：`spring.flyway.enabled=false`，改完迁移必须跑 `bash scripts/db-migrate.sh`，否则表结构不生效。
10. **同步方向**：E 盘文档工作区改 → `cp` 到 WSL 权威副本；**反向会覆盖 WSL 侧补丁**；9P 上禁止构建测试。
11. **shell 纪律**：复杂脚本写成 `.sh` 执行，不在 `bash -lc '...'` 里用 `$VAR`（跨层展开会静默变空）；Windows 写的文件先 `sed -i 's/\r$//'`。
12. **门禁纪律**：跑门禁期间不改它读的工作树文件（07/08/09/20/23 读工作树会假红）；收口前 `git restore` 已跟踪副产物。

**本文命令约定**（均在 WSL 内执行）：

```bash
dbq() { set -a; . ~/.config/robot-autotest/env; set +a; \
  mysql --default-character-set=utf8mb4 -h "$DB_HOST" -P "$DB_PORT" \
        -u "$DB_USERNAME" -p"$DB_PASSWORD" "$DB_NAME" -e "$1"; }
gate() { bash scripts/gates.sh; }
be()  { (cd backend && mvn -q test "$@"); }
fe()  { (cd frontend && npx vitest run "$@"); }
```

### W81-02 绑定人工确认（后端 + 审计）
- **对应**：FR-v5.31-01 ｜ **改动**：`CaseController`、`TestCaseService`、`CaseScriptBindingRepositoryJdbc`、`AuditService`
- **要点**：
  1. `POST /api/projects/{projectId}/cases/{caseId}/binding/confirm?kernel=pytest`：把该内核绑定 `verified` 置 1，写审计（用例编号、内核、脚本路径）。
  2. 批量 `POST .../binding/confirm-batch`：入参 caseIds，返回 `{ok, failed:[{caseId,reason}]}`，部分失败不回滚整体。
  3. 前置校验：绑定必须存在且 `script_sha256` 与当前文件一致（防确认过期绑定）；不一致返回 409 并提示先同步。
  4. 权限：`case:write`。
- **验收**：`be -Dtest=CaseBindingConfirmTest`；`dbq "SELECT verified,COUNT(*) FROM case_script_binding GROUP BY verified"`
- **判据**：单条确认后 `verified=1`；重复确认幂等（不重复写审计）；sha 不一致返回 409；无权限 403。
- **回滚**：接口下线即可，数据可用 `UPDATE ... SET verified=0` 还原（审计留存）。
