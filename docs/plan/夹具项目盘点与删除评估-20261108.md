## 3. 为什么「有数据的项目」删不掉（天然保护）

`ProjectRepositoryJdbc.delete()` 只清 `project_setting` / `project_label` / `project_member` 三张子表
就删 `project` 行；`run` / `test_case` / `test_report` 等租户表对 project 有外键引用——
**有数据的项目直接删会 FK 报错**，只能先清数据。这不是缺陷而是保护：A8 / demo / NODX 这类
带运行与报告的项目想删，必须先动冻结证据，等于强制先过大师这一关。
