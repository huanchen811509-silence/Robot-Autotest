## 1. 范围

**做什么**：把本轮暴露的合规硬伤、CI 质量门缺口、测试口径漂移补齐，并承接远程主机采集这一项明确的能力缺口。

**不做什么**：不代判 G 门、不宣称发版、不创建公开 Release（除非 D-01 授权）、不做 deb/rpm/Docker/Windows 安装包、
不在 GitHub-hosted CI 里跑真库 / 真浏览器 / 全量门禁、不改动既有 `pr.yml` 的 self-hosted 口径。

**基线**：`VERSION=3.11.0`，门禁 30 步，88 张业务表，OpenAPI 284 endpoints / 225 paths，i18n 1687/1687 键。

## 3. 非功能判据

| 项 | 判据 |
|---|---|
| 回归 | 横向回归不倒退：后端单测、前端单测、编辑器单测、`vue-tsc`、`vite build`、i18n、门禁 30 步（或当期步数）全 PASS |
| 证据 | 只认真链路：真 HTTP、真库、真浏览器；「单测绿 / 构建绿」不是放行理由 |
| 凭据 | 任何报告 / 日志 / 交付包 / MANIFEST 不得出现明文口令；两个既有密钥扫描器继续守住 |
| 只读 | 只读页源码级无写函数，运行时由 CDP `Network.requestWillBeSent` 证明加载期 0 写请求 |
| 流程 | 七道流程不跳步：调研 → 评估 → PRD → 开发计划 → 测试计划 → 测试执行 → **文档回写**；不回写 = 版本未完成 |
| 版本 | `VERSION` bump 与对外口径归大师；学徒不擅自 bump |

## 4. 架构决策（ADR 摘要）

| 编号 | 决策 | 理由 |
|---|---|---|
| ADR-312-01 | 交付流水线继续用 GitHub-hosted `ubuntu-latest`，质量门只加「无 DB」测试 | 真库 / CDP 无法在 hosted runner 复刻；口径分叉比少一道门更危险 |
| ADR-312-02 | `pr.yml` 保持 self-hosted 不动 | 它等的是现场 runner，不是代码问题；改了会把「待现场」伪装成「已解决」 |
| ADR-312-03 | 远程采集不新增命令类别 | `HostInventoryCollector.COMMANDS` 是唯一事实来源，扩类会破坏第 29 步机检 |
| ADR-312-04 | `SchemaIT` 与 `db-audit` 共享一份表数 / 豁免口径 | 双口径漂移已发生一次，靠同一份常量或生成脚本消除 |
| ADR-312-05 | Release job 不写进 workflow，除非 D-01 授权 | 对外口径归大师，避免「默认就公开」 |
| ADR-312-06 | 下一轮不引入 deb/rpm/Docker | 目标平台是 WSL2 / Ubuntu，现有 tar.gz + systemd --user 已满足 |

## 6. 验收总判据

1. `FR-v3.12-01` 必达（P0）；未达不得进入后续工作包。
2. P1 三条（`FR-v3.12-02/03/04`）逐条有真链路证据，且横向回归不倒退。
3. 候选四条状态明确写「未做 / 待授权」，不得用 `PARTIAL` 冒充通过。
4. 测试执行后完成 ⑦ 文档回写：PRD 验收状态、DEV-PLAN 偏差、TEST-PLAN 实测结果与遗留缺陷、评估报告修订记录。
5. 全量门禁 `GATES_RESULT FAILS=0`；四处 sha 一致；G 门判定仍由大师出书面结论。
