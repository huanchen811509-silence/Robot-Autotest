## 4. 开工前置（对每一版都成立）

| 前置 | 说明 |
|---|---|
| 上一版已落号 | 版本间严格串行；未落号不得开下一版 |
| 迁移已应用 | `spring.flyway.enabled: false`，改迁移后必须 `bash scripts/db-migrate.sh` |
| 前端已构建 | 改源码后 `npm run build`，否则 `serve-entry.mjs` 仍托管旧 dist |
| 环境变量 | 门禁前 `set -a; . ~/.config/robot-autotest/env; set +a` |
| 证据自证 | 断言脚本必须含负向自证（改动前应判红） |

## 5. 维护规则

1. **禁补号**：FR / WBS / TC 编号插入即整体重排；新增一律追加到该版区间末尾。
2. **每版收口必须回写**四处：PRD（验收状态）、DEV-PLAN（实际完成与偏差）、TEST-PLAN（实测结果与遗留）、06-TEST-REPORT。
3. **状态列更新**：版本落号后把本文第 2 章的"待评审"改为"已落号（sha）"。
4. **总纲与细则冲突**：以版本文件为准，并同步修正总纲（不留两份真值）。
5. **待裁决项**：`FR-v5.23-18` 裁决后，在本表与 v5.23.0 三件套中同步补 WBS/TC，并更新合计。
