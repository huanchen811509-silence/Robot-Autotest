## 3. 风险与回退

| 风险 | 触发信号 | 回退动作 |
|---|---|---|
| 机检误报拖慢门禁 | 单步 >60s 或频繁误红 | 缩小扫描范围；白名单按"路径 + 理由"登记；不改判据 |
| 截图基线抖动 | 动态数字导致 diff 超阈值 | 遮罩动态区域（选择器配置），不做模糊比对 |
| 引导打扰老账号 | 老账号也弹 | 判定条件改为"该账号无 run 记录"，不按时间 |
| 埋点影响性能 | 页面变慢 | 异步批量上报，失败静默丢弃（不影响业务） |
| 看板数据造假风险 | 比率与真实操作不符 | 看板直读 SQL 聚合，不做写时统计 |
