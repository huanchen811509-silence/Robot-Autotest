**跨版本并行纪律**

1. **版本间严格串行**：每版必须先落号再开下一版，否则 CHANGELOG、VERSION、交付包 MANIFEST 三处会错位。
2. **同一文件的改动不跨版本拆**：`TestReportService`、`ReportFieldWhitelist`、`zh-CN.ts` 在多个版本都要动，必须整版一次性改完再落号。
3. **术语替换（W75-01）先于一切文案类改动**：否则 v5.26 的视觉文案、v5.28 的报告章节名要改两遍。
4. **视觉版本（v5.26）的截图基线单独提交**：与功能提交分开，避免门禁第 13 步假红时无法定位。

**关键路径（决定总工期）**

```
W73-01(元数据模型+迁移) → W73-02(执行表单) → W73-03(补齐并重冻结) → W73-04(导出失败可见)
                                    ↓
```
