## 3. 风险与回退

| 风险 | 触发信号 | 回退动作 |
|---|---|---|
| PDF 页数失控 | SKIP 折叠后仍 >1 页 | 检查是否按"每条用例一段"渲染；改为按原因分组表格 |
| 章节开关影响历史报告 | 已冻结报告重新导出内容变了 | 冻结时快照即固定，渲染读快照不读当前配置 |
| 脱敏误删失败原因 | 对外版失败原因变成空白 | 脱敏只删路径/命令/exit 码，保留断言摘要 |
| AI 叙述接口不可用 | 超时或 5xx | 直接降级模板段落，不阻塞导出 |
| 审核态改动破坏既有导出 | 历史 FROZEN 报告无审批记录导致导出被拒 | 迁移时为存量 FROZEN 报告补一条系统审批记录（approver=SYSTEM，comment=迁移补齐），避免历史报告集体失效 |
| 批次规则引发结论争议 | 同一批次两次结论不同 | 批次结论必须可追溯到 run 清单；规则写进报告附录，不只写在文档 |
