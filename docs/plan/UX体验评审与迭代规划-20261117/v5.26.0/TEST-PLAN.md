# v5.26.0 测试计划（TEST-PLAN）：视觉收口

> 流程位置：⑤ 测试计划。上游：`PRD.md`（8 FR）、`DEV-PLAN.md`（3 波 8 WBS）。
> TC 编号：`TC-v5.26-01 ~ 16`，禁补号。前置：v5.25.0 已落号。
> 特别要求：所有可判定项都做成**度量断言**（宽度占比、行数、元素数），不靠人眼"看着还行"。

---

## 1. 范围

| 项 | 内容 |
|---|---|
| 测 | 主题一致性、按钮错位、分页图标、表头单行、长文本折叠、噪声聚合、双栏占比、tab 选中态 |
| 不测 | 配色体系本身的美感；动画性能 |
| 方式 | **UI**（Playwright 度量）/ **UT**（组件快照）/ **MECH** |
| 分辨率 | **1440×900 与 1280×800 两档都必须跑**（评审里 P2-8 只在窄卡片复现） |
