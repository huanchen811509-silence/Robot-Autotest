## 3. 风险与回退

| 风险 | 触发信号 | 回退动作 |
|---|---|---|
| 批量接口非原子 | 部分加入后成员数与请求不符 | 加事务；失败整体回滚；前端提示"未加入任何一条" |
| 全选按当前页取数 | 用户以为全选实际只选 20 条 | 全选必须带筛选条件重新查询 total，并在按钮上写「全选匹配的 N 条」 |
| 确认面板被绕过 | 快捷键/深链直接创建 run | 后端对 real 模式强制要求 `confirmToken`（v5.27 统一）；本版先做前端统一 |
| 试跑污染统计 | 今日 run 数被 dry-run 抬高 | `run` 表加 `dry_run` 语义标记（注意：`ops_task` 无此列，勿混用），统计查询显式排除 |
