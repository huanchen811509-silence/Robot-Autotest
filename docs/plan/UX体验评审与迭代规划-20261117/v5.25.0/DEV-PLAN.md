## 3. 风险与回退

| 风险 | 触发信号 | 回退动作 |
|---|---|---|
| i18n 键插错命名空间 | 页面出现字面 key（如 `diffTitle`），`check_i18n` 仍 PASS | 回滚该键；`grep -n "<键名>" src/locales/zh-CN.ts` 定位（同名键可能多处） |
| 术语替换误伤代码注释/日志 | 后端日志可读性下降 | 只替换**用户可见文案**常量，不动 `log.info` 与注释 |
| en-US 被中文污染 | 英文界面出现中文 | `check_terms.py` 同时校验 en-US 不含中文（白名单除外） |
| 标题机检误报 | 同名页（如"项目总览"两模式）被判不一致 | 机检允许前缀差异，配置在 `check_titles.py` 白名单 |
