## 3. 新增层 N 定案（AI 助手）

大师补充「AI 助手还不能用，也需要开发和完善功能」。学徒已核实根因并单出 `docs/plan/AI助手可用性评估增补-20261108.md`（第 ② 道增补），本版据此定案：

| 项 | 定案 |
|---|---|
| 定位 | **层 N**：把 AI 助手从「面板骨架 + 探针 + 审计占位」做成**真实可用的 L1–L3 助手**；与本版层 M 并列，不互相抵扣 |
| 根因 | `application/ai/` 全包无 `ProcessBuilder` / `Runtime.exec` / HTTP 客户端 / 模型端点；`AiPanelService.execute():80-82` 二次确认后只写审计返回拼好的文案、`suggest():54-63` 只回固定模板。三条在册缺口 G-A9-1 / G-A9-2 / G-A9-3 全部属实 |
| 接入方式 | 沿用 v2.0 评估 D6 已定裁决 **A（本机 CLI 子进程）**，**不引入远程 API Key 托管**（规划 §3.2 非目标） |
| 做 | 真实 CLI 子进程调用（按 CLI 分别适配 argv）、会话持久化与全局唯一 id、`ai_action` / `ai_cli_probe` 落库、前端文本输入与结果呈现、`ai.enabled` 开关接线、L2 真实建议、`terminate` 真能终止进程树、假 CLI 全链路自动化验证 |
| 不做 | AI L4–L5（自动改代码 / 自动提交）、远程 API Key 托管、用例录制回放、报告结论自由编辑；沿用中长期规划 §3.2 与 v2.0 PRD §8 |
| 真实模型调用 | 开发期用**可注入的假 CLI** 验证编排、降级、超时、终止、审计；**真实本机 CLI 调用（消耗已登录凭据与 token）归 `G-授权`**，学徒不擅自发起，相关 TC 记 `BLOCKED` 并写明解除条件，等大师一句话再跑 |
| 优先级 | 与层 M 同为 P3；层 N 内部先修 G-A9-1/2/3（可用性硬缺口），再做完善项 |
| 锚点 | 新增 FR-AI-01..08 / WBS AI-01..06 / TC-AI-01..10，见四份文档的增补章节；不与 FR-v2.2-01..28 / TC-v2.2-01..36 混号 |
