## 7. 取证策略

| 层级 | 做法 | 反例（禁止） |
|---|---|---|
| 静态 | 机检器 + `--self-check` 正负样本，判据要能变红 | 只跑正样本、恒定返回 0 |
| 单测 | 纯逻辑抽到 `utils/` 或 Java 测试类，避开虚拟列表 | 用夹具自证真链路 |
| 真 HTTP | 先登录拿 token，再采真实接口与真库读数 | 直接 INSERT 假行当证据 |
| 真浏览器 | CDP `:9222` 录 `Network.requestWillBeSent` 证明只读 | 只靠源码断言「没写方法」 |
| 负向 | 备份 → 注入 → 定向判据必须红 → 用备份还原 → 复跑绿 | 用 `git checkout` 还原 |
| CI | `gh run view` 取真实结论，失败修到绿再归档 | 把 `pending` 当成功 |
