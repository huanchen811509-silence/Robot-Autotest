**顺序纪律**：

1. `W40-01`（P0 合规）未达，不得开 `W40-02` 至 `W40-05`，更不得开 4.1。
2. `W40-02` 是所有新界面（账户下拉、向导、工作区浏览器）的**基座**，必须先于 `W40-03` / `W41-05`。
3. `W41-01` 的 ADR 未评审通过，不得写 `W41-02/03` 的任何同步代码（防双真源）。
4. 候选四条 `FR-v4.2-05` 至 `FR-v4.2-08` **不进本批**；授权后另开工作包与 TC 编号段。
5. 更新演练（`W40-05`）只在临时 prefix + 非生产库上做；真生产库升级须大师单独授权。
6. `W41-06` 工作区 UI 必须复用 `W40-02` 浮层基座，且依赖 `W41-02/03` 的契约与 dry-run 报告，不得先写自绘弹层。
7. 导入未验签 bundle、恶意脚本、成员自动授权三项负向样本未绿，4.1 不得收口。
8. 更新演练脚本必须版本化在 `scripts/ops/update-drill.sh`，不得用 `/tmp` 临时脚本作为验收依据；`W42-01` 必须先证明后端非 IT 单测无 MySQL 可跑，再启用 CI 门。
