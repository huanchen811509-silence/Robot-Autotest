> 版本：不 bump `VERSION`（仍 5.23.0）

---

## 0. 一句话

把两个用例集页面从"320px 中栏塞表格"改成"全宽列表 + 抽屉"，把 pytest 工程的项目用例按编号从公共库**一次性回填**内容，把用例集执行**按内核分派**，并把报告的三处计数/结论/门禁**收敛到同一口径**。

## 2. 用户故事与判据

### A 批 · 用例集页面形态

#### FR-UIE-01 用例集列表铺满内容区，行内打开抽屉

- **故事**：作为测试负责人，我要在列表里一眼认出「虚拟化与容器测试」这个集，而不是只看得到 `032 40条`。
- **判据**
  1. 1440×900、1920×1080、1366×768 三档视口下，列表区域宽度 = 内容区宽度（≥ 900px），**不存在固定 320px 中栏**；
  2. 每一行同时可见：集代号、集名称、成员数、脚本覆盖（`已绑定 X/Y`）、状态；
  3. 点击行（非按钮区）打开右侧抽屉，URL 变为 `?set=<id>`；关闭抽屉后 `set` 参数被移除；
  4. 直接访问 `?set=<id>` 能恢复同一抽屉（刷新/分享可还原）；
  5. 抽屉宽度 ≥ 720px，内部成员表不出现横向滚动。
- **现状反证**：1920 下集名称可见像素 = 0（评估报告 §3.3）。

#### FR-UIE-02 集行操作唯一化

- **判据**
  1. 每行可见按钮 ≤ 1 个（主操作「查看成员」/「管理用例」）；
  2. 编辑、删除收进「更多」菜单，菜单项点击后行为与现版一致（删除仍走二次确认并说明影响条数）；
  3. 行高 ≤ 56px（现在约 150px）；
  4. 无「全选匹配当前筛选」这类与"选集合"语义无关的批量条出现在列表顶部。

#### FR-UIE-03 成员表行布局与操作收敛

- **判据**
  1. 成员行高 ≤ 56px；1440 与 1920 下均不换行；
  2. 可见列：序号、用例编号、用例名称、优先级、脚本状态、操作；
  3. 上移/下移/移除收进「更多」或行尾图标，**不得出现一字一行**；
  4. 拖拽或键盘上下移动仍可用（保留现有 `reorder` 接口）。

#### FR-UIE-04 加成员改为选择器

- **判据**
  1. 页面不出现"用例 ID"数字输入框；
  2. 「添加用例」打开选择器：支持关键词 + 分类 + 脚本状态筛选，可多选，一次提交；
  3. 选 10 条提交后返回 `added=10, skipped=0`，成员 `seq_no` 连续（不撞 `(test_set_id, seq_no)` 唯一键）；
  4. 重复加入同一用例时 `skipped` 计数 +1，不报错。

#### FR-UIE-05 脚本状态真实渲染 + 集级覆盖

- **判据**
  1. 成员表"脚本"列按 `bindingState` 四态渲染，与 `case_script_binding` 逐条一致（同一 `case_code` 在项目库/公共库/用例集三处文案逐字相同）；
  2. 集行显示 `已绑定 X/Y`；Y 为该集成员数；
  3. 公共库（robot 内核）显示「不适用」仍允许，但必须由 `bindingState=NOT_APPLICABLE` 得出，不得硬编码。

#### FR-UIE-06 空态与主操作唯一

- **判据**
  1. 两页各自只有 1 个空态、1 个主按钮；
  2. 项目用例集页的「平台用例集库」不再与主列表同栏争宽：改为顶部入口链接或折叠区；
  3. 空态提供三个动作：新建用例集 / 从平台库引用 / 从用例库加成员。

### B 批 · 用例详情继承

#### FR-UIE-07 公共库 → 项目用例内容一次性回填

- **故事**：作为用例维护人，我打开 `IM-FUN-001` 想看到预置条件和步骤，而不是四个「源表无值」。
- **判据**
  1. 提供 dry-run：返回 `将填充 N 条 / 跳过 M 条`，并逐条给出跳过原因（目标字段非空、公共库无同编号、编号冲突多条）；
  2. 执行后，对每个命中 `(project_id, case_code)` 的项目用例，`precondition` / `expected` / `case_kind` 与公共库**逐字一致**；`test_case_step` 条数与 `step_no` 序列一致；
  3. **幂等**：同一批重跑，`将填充 0 条`（已填字段不再动）；
  4. **不覆盖本地修改**：目标字段非空即跳过，并在结果里计数；
  5. 回填记录可追溯：每条被回填的用例写入来源标记（形如 `global-inherit:<公共库case_id>`）与回填批次号；
  6. 默认只处理 `project.kind='pytest-suite'`；其他工程需显式传 `projectId` 才执行。
- **实测基线**：项目 95 期望 `将填充 414 条 / 跳过 71 条（公共库无同编号）`。

#### FR-UIE-08 详情展示来源与空值语义

- **判据**
  1. 内容组（预置条件/步骤/预期）下方显示一行来源：`内容来源：公共库 IM-FUN-001（继承于 2026-11-21）`；
  2. 三种状态文案互不相同：
     - 字段本身有值 → 正常显示；
     - 公共库也没有 → `源表无值`；
     - 未回填且公共库有值 → `未继承（公共库有值）` 并提供"立即继承"提示（只读用户不显示动作）；
  3. 本地改过的字段显示 `本地覆盖` 徽章，且重跑回填不会覆盖。

### C 批 · pytest 用例集执行

#### FR-UIE-09 用例集执行按内核分派

- **判据**
  1. `POST /api/execution/test-sets/{id}/run?projectId=<id>` 读 `project.test_kernel`：
     - `pytest` → 用 `case_script_binding` 解析 nodeId，下发 pytest 内核（fake/real 与工作台同一套闸）；
     - `robot` → 保持现有 `CaseScriptResolver` 行为，逐字不变；
  2. pytest 分支产生的 run 记录 `kernel='pytest'`，`total_tests` = 集合内已绑定条数；
  3. 未绑定用例仍按"存在未绑定 → 400 并列编号"处理，但文案不得再让 pytest 用户去写 RF `[Tags]`（改为"该用例未绑定脚本，请在 pytest 工作台同步绑定"）；
  4. real 模式仍需 `confirmReal=true` + ADR-0013 安全闸，**不得因分派而放宽**。

#### FR-UIE-10 安全级拒绝可解释、可处置

- **判据**
  1. 集行与成员行显示 `LX 未判定 N 条` 角标（N>0 才显示）；
  2. 403 回执同时给出：受阻编号清单（≤10 条 + 总数）、每条的安全级、单条处置入口（跳「用例定级」）；
  3. 不静默剔除：回执与 run 记录都不产生"少跑几条"的静默行为。

### D 批 · 报告口径

#### FR-UIE-11 进度计数不把 skip 记成 pass

- **判据**
  1. 一份 `tests=10 skipped=10 failures=0` 的 junit，进度接口返回 `finished=10 passed=0 failed=0 skipped=10`；
  2. 进度三数之和 = junit `tests`；
  3. 页面进度区能显示 `跳过` 一档（现在只有通过/失败）。

#### FR-UIE-12 结论判定与计数同源

- **判据**
  1. 判定表：`fail>0 → FAILED`；`fail=0 且 pass>0 → PASSED`；`pass=0 且 skip>0 → INCONCLUSIVE`（中文「无有效结论」）；`total=0 → NO_DATA`；
  2. 报告详情页顶部结论、`/summary` 的 `conclusion`、报告列表的结论徽章三处**同值**；
  3. 页面不得出现"通过率 0% + 结论 PASSED"同时出现。

#### FR-UIE-13 跳过原因采集 + 导出门禁同源

- **判据**
  1. 报告能列出每条 skip 的原因文本（来源 `junit <skipped message>`），至少覆盖「Plan-only：AW 未真实执行」这一类；
  2. 报告页不再出现"本次未采集逐条跳过原因，无法归因"这句话（除非 junit 确实无 message）；
  3. 发起执行的元数据表单字段集 = `MetadataGate.REQUIRED` 10 项（新增 `STARTED_AT` 与 `CASE_KIND`）；
  4. 缺项在**提交前**提示（可继续，但明确告知"本次报告不可对外交付"），不再等导出时 400。

## 4. 不做清单

| 不做 | 原因 |
|---|---|
| 保留 320px 三栏中栏 | 已裁定改为全宽 + 抽屉 |
| 实时引用公共库（读时联查） | 已裁定用快照；实时引用会让公共库停用导致项目详情变空 |
| 新增"动态智能集" | 与 `FR-READY` 已裁定的静态快照口径冲突 |
| 追溯重算历史报告结论 | 快照已定稿；只对新入库记录生效 |
| 改 `test_set` / `test_case_step` 表结构 | 本批无必要；回填批次表见开放项 O-1 |
| 给 16 条手工用例逐条定级 | 属数据治理，另行安排 |
