## 1. 需求背景与判据原则

四条诉求来自大师 2026-11-08。第 ② 道评估已把现状与缺口定清，本节只重复与需求判定直接相关的事实：

| 事实 | 读数 | 来源 |
|---|---|---|
| 一级菜单已是 8 组两级结构 | 8 组 / 2 叶子 / 6 分组 / 19 个二级入口 | `frontend/src/config/navigation.ts` |
| 同一页面两个名字 | 侧栏「工作台」vs 页头「总览」 | `navigation.ts:56` 与 `OverviewView.vue:239` |
| 工作台强依赖当前项目，无跨项目视图 | `/overview` 首行即判 `projectId` | `OverviewView.vue:74`、`:252` |
| 项目 DTO 无统计字段 | 6 个字段，无任何计数 | `api/iam.ts:33-41` |
| 顶栏 9 个常驻交互控件 | 7 按钮 + 2 原生下拉 | `App.vue:289-380` |
| 主题已三模式六强调色两密度 | 12 个强调色变体块 | `theme.css:268-380` |
| 滚动条零样式 | `-webkit-scrollbar` 全仓 0 命中 | 全仓 grep |

**判据原则（本 PRD 的硬要求）**：每条 FR 必须能被一条命令或一条单测判定。写不出判据的需求不入本表——宁可降成 NFR 或列入「不做」。

## 3. 功能需求：工作台项目总览（FR-UI-09..14）

| 编号 | 需求 | 优先级 | 验收判据 |
|---|---|---|---|
| FR-UI-09 | 新增只读端点 `GET /api/projects/cards?window=7d`，一次返回当前用户可见的全部项目卡牌数据 | P0 | 真实 HTTP 200；响应 `data` 为数组，每项含 `id/code/name/enabled/visibility/ownerId/isCurrent/caseCount/runCount/passRateBp/lastRunAt/deviceCount/memberCount/myRole` |
| FR-UI-10 | 卡牌可见范围与现有项目列表完全一致，复用 `projects.visible()` 口径，不新写权限判断 | P0 | 负向测试：非项目成员调用该端点，返回列表不含该项目；与 `GET /api/projects` 的返回集合逐 id 相等 |
| FR-UI-11 | 卡牌分三层展示：必有层（名称、代码、状态、当前项目标记）、概要层（用例数、近 7 天运行数、近 7 天通过率、最近运行时间）、细节层（设备数、成员数、可见性、我的角色、描述） | P0 | 组件测试逐字段断言渲染文本；缺数据时显示「—」而不是 0 或空白 |
| FR-UI-12 | 卡牌页支持搜索（名称/代码）、排序（最近活跃、名称）、空态、加载骨架、错误行 | P1 | 组件测试断言：搜索过滤后数量变化；两种排序首项不同；无项目时显示空态文案；接口失败时显示错误行且不显示假数据 |
| FR-UI-13 | 两种切换语义分离：「进入」= 设为当前项目并跳 `/overview`；「设为当前」= 只改当前项目，停留原页 | P0 | 组件测试断言两个按钮的 store 调用与路由跳转差异；当前项目卡有 `aria-current="true"` |
| FR-UI-14 | 卡牌页不得为每个项目单独发请求 | P0 | 浏览器回归断言：进入 `/workbench` 后 `/api/projects/cards` 请求数 = 1，且无 `/api/projects/{id}/overview` 请求 |

**卡牌字段的来源口径**（避免「数字从哪来」说不清）：

| 字段 | 口径 | 来源表 |
|---|---|---|
| caseCount | 该项目启用中的用例数 | `test_case` |
| runCount | 近 N 天（默认 7）已结束运行数 | `run` |
| passRateBp | 近 N 天用例级通过率（万分比） | `test_result` |
| lastRunAt | 该项目最近一次已结束运行的开始时间 | `run` |
| deviceCount | 该项目设备数 | `device` |
| memberCount | 项目成员数 | `project_member` |
| myRole | 当前用户在该项目的角色码 | `project_member` |
| isCurrent | 是否等于前端当前项目 | 前端传入或后端比较请求头 |

## 5. 功能需求：主题 / 强调色 / 滚动条（FR-UI-20..25）

| 编号 | 需求 | 优先级 | 验收判据 |
|---|---|---|---|

## 9. 附录 B：顶栏结构（目标态）

```text
┌──────────────────────────────────────────────────────────────────────────┐
│ [项目切换触发器: 项目名 ●]        检索 │ AI │ 外观 ─ 用户菜单(首字母)     │
└──────────────────────────────────────────────────────────────────────────┘
```

| 位置 | 元素 | 行为 | 备注 |
|---|---|---|---|
| 左 | 项目切换触发器 | 显示当前项目名 + 状态点；点击开面板（搜索 + 列表 + 「查看全部项目」跳 `/workbench`） | 未选项目时显示引导 |

| 右 2 段 | 外观 | 打开弹层（主题三选 + 强调色六选 + 密度二选） | 合并原「主题快捷按钮」与「外观」两个入口 |
