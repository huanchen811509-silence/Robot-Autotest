### 2.1 三个缺陷的根因（接手人最该记住的部分）

| 现象 | 真因 | 为什么之前没人发现 |
|---|---|---|
| 退出按钮「点了没反应」 | `auth.logout()` **先 await 服务端撤销再本地清理**；后端慢/挂住时 token 还在、页面不跳 | 正常网络下请求很快就绿，看不出依赖顺序 |
| 账户按钮「看得见位置却点不到」 | 顶栏 `flex-wrap: nowrap`，账户区在最右，视口不足时被推出可视区（仍占位） | 1440 宽下不触发；只有窄屏才暴露 |
| 菜单只剩图标 | ① v2.3 折叠按钮搬到侧栏后旧键 `robot.layout.side.collapsed` 无人认领；② `@media(max-width:999px)` 只压宽度不藏文字，文字被 overflow 裁掉 | 新用户 localStorage 干净 → 复现不到；老用户升级才中招 |

**教训**：前两条都是「看起来是 UI 坏了，实际是时序 / 布局契约错了」。修的时候必须**两条都修**，
只修一条会被另一条掩盖，表现仍是「修了没用」。

### 3.3 已知取舍与边界（有意为之，勿当缺陷）

| 项 | 边界 | 原因 |
|---|---|---|
| AI 配置粒度 | 全局单份（每 CLI 一行），不做按项目/按用户分层 | 分层需先定义覆盖顺序，要走 ADR |
| 密钥托管 | 不接 Vault / KMS，沿用 `SecretCipher` + `CRED_MASTER_KEY` | 换密钥管理方案是另一件事 |
| 候选顺序 | 不开放给用户调整 | 系统提示词要求候选完整，顺序属实现细节 |
| 分片「两节点」 | 进程内假 agent，非物理双机 | 等价性已实测；真实网络分区未覆盖 |
| 性能基线 | 劣化判据 = 超基线 10% **且** 绝对增量 > 30ms | WSL 宿主 load 3+，15ms 会把调度噪声判成回归 |
| 登录「记住密码」 | localStorage 明文 | 内网自动登录诉求下的选择 |
| `run.node_id` 历史 NULL | 不回填 | 不伪造历史事实 |

## 4. 环境与运维（接手即用）

| 项 | 值 |
|---|---|
| 权威副本 | WSL `~/robot-autotest`（ext4）；`E:\` 副本冻结只读；9P 上禁止构建/测试 |
| 统一入口 | `:8001`（`scripts/serve-entry.mjs`）；后端 `:8081`；节点 `:8082/:8083` |
| 凭据 | `~/.config/robot-autotest/env`（`DB_*`、`CRED_MASTER_KEY`、`QA_E2E_PASSWORD`、`ARK_API_KEY` 等） |
| **跑门禁前必做** | `set -a; . ~/.config/robot-autotest/env; set +a`（缺 `CRED_MASTER_KEY` 会让 WS E2E 起不来） |
| 服务托管 | systemd --user 三件套跑的是 `backend/target/*.jar`；**改源码不重建 jar + 不 restart = 线上仍旧行为** |
| 门禁 | `bash scripts/gates.sh`（19 步）；单跑静态检查 `bash scripts/lint.sh` |
| 迁移 | `bash scripts/db-migrate.sh`；回滚脚本在 `db/down/`；已应用迁移**不可改**，只能追加 |
| 版本号 | 改 `VERSION` 一行 → `scripts/gen_build_info.py` 写进产物；`APP_VERSION` 可运行期覆盖（重启生效） |
| AI 助手配置 | 设置 → AI 助手（`/settings/ai`）；仅管理员（`ai:config`）；「测试连接」真实跑 CLI 并写审计 |
| 性能基线 | `python3 tools/perf_baseline.py`；基线 `docs/evidence/perf-baseline.json`，重建加 `--update` |
| 备份演练 | `bash scripts/backup-drill.sh` |
| 浏览器取证 | `node scripts/w4-capture.mjs` / `w5-capture.mjs`（需 Chrome CDP `127.0.0.1:9222`，**当前不可用**） |
| 双远程 | `git push origin main`（群晖）+ `git push github main`；判据是两处 sha 一致 |
| 环境坑 | ① `wsl.exe ... bash -lc '... $VAR ...'` 里 `$VAR`/`$(...)`/**反引号**会被外层 Git Bash 提前展开 —— 复杂脚本写成 Windows 临时文件再 `... bash /tmp/x.sh`；`bash -s < 文件` 会被子进程吞掉剩余脚本；<br>② RF `--dryrun` 退出码不可信，要双判 `[ ERROR ]`；<br>③ pabot 子进程需显式 PATH；<br>④ systemd `Environment=A=1 B=2` 会按空格拆成多个赋值，多词值必须整体加引号；<br>⑤ 内置 agent 不能依赖调用方 PATH 上的 node（shebang 是 `/usr/bin/env node`）；<br>⑥ 就绪探针不能用 `:8001/_ping`（入口自己回的 200），要打 `:8081` |
