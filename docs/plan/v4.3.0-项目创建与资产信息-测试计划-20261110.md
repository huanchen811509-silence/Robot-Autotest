## 3. 取证策略

| 层级 | 做法 | 反例（禁止） |
|---|---|---|
| 静态 | `navigation.spec` / `PermissionMatrixTest` / `AuthzMatrixTest` 断言走真实常量 | 复制常量到测试里自证 |
| 单测 | 派生、缓存键、指纹、单飞抽到可注入依赖的类；`AssetInfoServiceTest` / `AssetInfoCacheTest` | 用夹具自证真链路 |
| 真 HTTP | 四角色各取 token，采真实接口与真库读数 | 直接 INSERT 假行 |
| 真浏览器 | CDP 录 `Network.requestWillBeSent` 证明只读；量 DOM 证明两菜单并列 | 只靠源码断言「没写方法」 |
| 真缓存 | 改 TTL / 等过期 / 变更资产，读 `meta.cacheHit` 与日志计数 | 只看 `meta` 不验证重算次数 |
| 负向 | 备份 → 注入 → 定向判据必须红 → **用备份拷贝还原** → 复跑绿 | 用 `git checkout` 还原 |
| 性能 | 20 次采样取 P95，样本与数据规模同时记录 | 单次读数当结论 |
| 迁移 | `robot_it` 上正向/回滚/再正向，禁在生产库试 | 只跑正向 |

## 6. 风险与依赖

| # | 风险 / 依赖 | 处置 |
|---|---|---|
| 1 | CDP `:9222` 波动导致交互类 TC 无法执行 | 每次开测前探活；不可用时记 `NOT-RUN`，恢复后补测，不得用源码断言冒充 |
| 2 | `P-BIG` 数据量大，创建耗时 | 用既有导入工具批量生成；计数以库内查询为准 |
| 3 | 12h 窗口无法真实等待 | 通过临时下调 `asset-info.cache.ttl-seconds`（如 5s）模拟过期，改后恢复并记录 |
| 4 | 并发 refresh 单飞难复现 | 脚本同时发 10 请求 + 日志 `recomputed` 计数为判据，不以时长判定 |
| 5 | 四角色切换需多账号 | 使用四个测试账号；令牌获取与切换过程留日志 |
| 6 | 迁移在真库执行有风险 | 只在 `robot_it` 演练；`robot_dev` 迁移前 `mysqldump` 备份 |
| 7 | 负向注入可能遗留临时改动 | 注入前备份文件、还原后 `git diff` 必须为空 |
| 8 | P1 未交付导致 `TC-v4.3-30` 空转 | 记 `NOT-RUN` 并在报告中写明授权与后续补测计划 |
| 9 | 别名串项目属 S1，一旦复现立即暂停 | 以 `TC-v4.3-18` + `TC-v4.3-33` 双重拦截 |
| 10 | 缓存命中率与冷启动性能受机器负载影响 | 记录机器负载与采样时间；P95 判据同时给原始采样表 |
