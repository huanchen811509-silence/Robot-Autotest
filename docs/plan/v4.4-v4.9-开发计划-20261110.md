## 0. 执行摘要

1. **先地基后界面**：4.4 只做权限与成员的数据与求值，不碰页面结构；4.5 才动顶栏与导航。这样 4.5 之后不再回头改权限模型。
2. **每个主线版本一个「不可逆点」**：4.4 的 `project_member_role`、4.5 的 `project.kind`、4.6 的 `external_id/content_sha`、4.7 的资产业务键、4.8 的模板三表、4.9 的 `sync_job`。不可逆点必须在版本内完成回滚演练。
3. **补丁版本只做三件事**：加固（越权/边界）、优化（体验/性能）、缺陷。补丁不新开 FR，不改数据模型。
4. **一切以 WSL 权威副本为准**：Windows 侧只编辑，构建、测试、门禁、取证都在 `~/robot-autotest` 执行。
5. **测试计划同步落地**：`RA-TST-2026-044` 与本文件同批评审，用例 ID 与本文件任务 ID 双向可追。

### 1.2 范围

- **做**：权限与成员多角色、全局/项目双模式、平台项目与公共库、幂等导入、反向导出、资产导入与引用、模板持久化与向导选用、存量同步、品牌与顶栏优化、性能与收尾。
- **不做**：用例协同编辑、执行内核改造、AI 生成用例、移动端 App、多租户计费、Excel 公式引擎（详见 PRD §1.4）。

### 1.3 开发纪律（违反即打回）

1. **FR 编号不可变**：实现与 PRD 不一致时，在该版 PRD 摘要写偏差，不回改上游编号。
2. **迁移必须成对**：每个 `V11_xx` 必须有 down 脚本，且在本版内完成一次 down→up 演练。
3. **先写测试再改行为**：权限求值、幂等、round-trip、同步 diff 四类必须有失败用例先行。
4. **不新建第二套数据模型**：公共库复用平台项目作用域；模板不复刻用例表。
5. **文案走 i18n**：新增中文必须同时补 `en-US`，禁止页面硬编码。
6. **证据可复现**：截图含时间/版本；脚本入 `scripts/` 或 `tools/`，不留在 `/tmp`。
7. **临时物当日清**：`logs/tmp-*`、`/tmp/*.sh`、临时 JSON 当天删除。

## 13. 风险与依赖

| 风险 | 影响版本 | 应对 |
|---|---|---|
| 平台项目被误删/误改 | 4.5+ | `kind='platform'` 硬保护；删除接口直接拒绝；单测断言 |

| 模板悬空引用 | 4.8+ | 允许悬空；应用时跳过并提示 |
| 删「管理」后入口不可达 | 4.5.1 | 旧路由保留；页脚入口；`?` 快捷键；上线说明 |
