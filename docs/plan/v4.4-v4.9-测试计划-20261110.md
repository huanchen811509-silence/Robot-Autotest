## 0. 测试治理

### 0.1 准入（不满足不开测）

1. 该版 FR 冻结，DEV-PLAN 任务完成并自测通过；
2. 迁移在本机库跑通正/回滚；
3. 构建产物可启动（前端 `dist` 与后端同一版本号）；
4. 测试数据与样本工作簿校验和一致；
5. 该版 PRD 摘要、DEV-PLAN 摘要已入库。

### 0.2 准出（不满足不发版）

1. 本版主用例 100% 执行，通过率 100%，无 P1/P2 未闭环；
2. 回归集 `REG-*` 相关项全绿；
3. 权限矩阵全格无漏测，越权 0；
4. 迁移回滚演练通过；
5. 文档/i18n/门禁机检达标；

## 5. 专项一：幂等与 round-trip

### 5.1 幂等矩阵（4.6 / 4.9 必测）

| 场景 | 文件 sha | idempotency_key | 行内容 | 期望 |
|---|---|---|---|---|
| 同文件同 key 重提 | 同 | 同 | 同 | 返回首批次，新增 0 |
| 同文件新 key | 同 | 异 | 同 | 新批次或复用，新增 0、版本 0 |
| 复制文件（内容同） | 同 | 异 | 同 | 新增 0、版本 0 |
| 改一行正文 | 异 | 异 | 变 1 行 | 新增 0、版本 +1 |
| 加一行 | 异 | 异 | +1 行 | 新增 +1、版本 +1 |
| 删一行 | 异 | 异 | -1 行 | 软失效 +1，不物理删 |
| 同步重复执行 | — | 同批次 | — | no-op |

### 5.2 round-trip 差异口径

1. 比较键：`(suite, external_id)` 或 `content_key`；
2. 比较字段：用例名称、前置条件、步骤、预期、分类 L1/L2、优先级、资源引用；
3. 归一化：去首尾空格、合并空行、全角转半角、日期统一 `YYYY-MM-DD`；
4. **忽略**：看板派生页、空行、样式、列宽、批注；
5. 判据：差异条目 = 0；非 0 时输出「键 + 字段 + 源值 + 导出值」三列报告。
