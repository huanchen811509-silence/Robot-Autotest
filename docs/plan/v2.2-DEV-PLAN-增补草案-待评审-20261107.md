## 4. 关键实现约定

1. **导入事务**：`EDIM-01..05` 全部走 `preview → commit` 两步，preview 不落库，commit 单事务整批回滚（沿用 `CaseImportService.java:123-235` 现有结构，不重写）。
2. **静默丢弃归零**：`CaseImportService.java:36-44` 的类注释与实现同步改掉；未识别列进入预检报告的「未映射列」清单，**不再静默忽略**。
3. **历史与当前分离**：任何写当前结论的路径不得写历史列；`EVID-04` 用单测锁死（NFR-v2.2-05）。
4. **证据不可变**：归档文件写后只读，SHA 入 `run_artifact`；改写尝试记审计日志（NFR-v2.2-04）。
5. **三轮实现口径**：不照搬 demo 的 `data/case-records/.../round-N/` 目录，改为 **3 个独立 `RUN_ID` + `run.round_no`**，避免与本平台 `run` 主键模型冲突（评估报告 §6.4 L5）。
6. **不引入设备侧代码**：`services/` 下不新增任何 SSH / 采集 / 执行器模块；`collectors` 包不在本版改动范围（NFR-v2.2-02）。
7. **output.xml metadata**：键名全大写、值 ≤40 字符、不放凭据；`RUN_ID` 键名不可改（项目硬规矩 `AGENTS.md` §4.1）。
