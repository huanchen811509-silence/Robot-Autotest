# v5.17.0 / v5.18.0 过程草稿归档（2026-11-16）

> **这是什么**：两个版本在流程 ③④⑤（PRD / 开发计划 / 测试计划）阶段的开工版原件。
>
> **为什么单独放这里**：`docs/release/vX.Y.0/` 的口径是「每版六份交付物」，过程草稿进去会混淆
> 「交付物」与「过程件」；而草稿原目录 `docs/release/_draft/` 已被 `.gitignore` 排除，只在 WSL
> 磁盘上，跨机与重新克隆都拿不到。本目录是它的持久化副本（2026-11-16 大师要求归档）。

## 3. 这份归档能回答什么

- 「评估报告在定稿前是什么样」——v5.17.0 的 `01-ASSESSMENT.md` 是唯一有实质差异的样本，
  可看出「前置条件」章节是后来补的，不是一开始就有。
- 「PRD 与计划有没有在中途被改」——就这两版而言没有：PRD、开发计划、测试计划三份从开工到
  定稿一字未动，说明开工时的判据是站得住的。

## 4. 已知限制

- 本目录是**复制件**，后续不要再往里编辑；要改文档请改 `docs/release/vX.Y.0/` 下的定稿。
- 草稿原件仍在 `docs/release/_draft/`（被 `.gitignore` 排除），内容与本目录一致。
- 只归档了 v5.17.0 与 v5.18.0；更早版本（v5.9 ~ v5.16）的 `_draft` 未按此方式归档。
