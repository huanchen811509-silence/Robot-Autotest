# v5.17.0 产品需求文档（PRD）：缺口闭合（一）取证与接线

> 流程位置：③ PRD（`docs/process/版本开发流程.md` §2.3）。

## 1. 版本定位

| 项 | 内容 |
|---|---|
| 一句话 | 把九版欠账里**只差取证**和**只差一段接线**的 7 项一次清掉；不新建组件、不动大页面 |
| 性质 | **清偿版（上半）**：按 D-1 拆版，本版只做「跑一遍就有证据」与「接一根线就通」的两类 |
| 下游 | `v5.18.0` 做剩下 6 项建设 + 1 项清场 |
| 不追求 | 不做导入向导、不做行数收敛、不做拓扑三件、不做运维真机动作（全部在 5.18） |

### 1.1 为什么这 7 项先做

它们**不依赖任何未定稿的设计**：模板列表 API 已在、场景同表、凭证名在 `credential.name`、性能脚本已在、
`V11_73` 已落列。做完这 7 项，账面上的「未达成」就从 11 项降到 4 项，剩下的都是要从零建的重活。

## 2. 约束与术语

| 术语 | 含义 |
|---|---|
| 真模板 | 后端 `project_template` 的行（`GET /api/global/templates`），区别于前端静态 `PROJECT_TEMPLATES` |
| 场景 | `test_set.kind='scenario'` 的集合（`api/cases.ts:351` 自述）；本版按 D-4 走「复用 `caseSetIds` + 服务端 kind 校验」 |
| 原子快照 | 选用例集时固化成员；之后改源集不影响已建对象 |
| 掩码凭证名 | 只显示首尾若干字符（如 `gpu-***-01`），不返回 `secret_ref` |
| 产品口径 | 数据集 1000 行、**页面每页 100 行**的真实页面；不是一次性 HTML 铺 1000 行 |

**硬约束**：

1. **不新增第二套写入 API**：所有改动都是「既有端点 + 可选参数」或纯前端。
2. **本版零迁移**（预期）；若必须加列从 `V11_79` 起并配 `.down.sql`。
3. **本版造数必须可逆**：演示项目用 `is_demo=1`、压测用 `PERF-` 前缀，收口前残留 0。
4. **取证类不得改判据换结论**（FR-03/07 是「跑一遍拿证据」）。

## 4. 需求详述

### FR-v5.17-01 项目向导第 1 步接真模板【P0】

**描述**：第 1 步由前端静态 `PROJECT_TEMPLATES` 改为 `templateApi.list()`；选中后 `templateApi.detail(id)`
带出 `kernel`、四类明细计数与资产计数，写入第 3 步默认内核。后端不可用时回退静态卡**并标「离线模板」**。

**验收判据**

| # | 判据 | 证据形态 |
|---|---|---|
| 1 | 卡片来自 `GET /api/global/templates`，且含本版之前新建的模板 | 真实网络日志 + 截图 |
| 2 | 选 `kernel=pytest` → 第 3 步默认 pytest；选 `kernel=robot` → robot | 截图 ×2 |
| 3 | 卡片 `itemCount` = 详情四类计数之和 | 真实响应 + DOM 断言 |
| 4 | 列表为空 → 空态 + 「去新建模板」入口，流程不崩 | 截图 |
| 5 | 后端不可用 → 回退静态卡且带「离线模板」标识 | 截图 + 代码路径检查 |
| 6 | 反向判据：在 `876da9b` 上无该请求，判据 1 必红 | 回放日志 |

### FR-v5.17-02 场景来源与快照语义【P1】

**描述**：`WizardContentPicker` 增 `scenario` 分区；按 **D-4 路径 A** 复用 `caseSetIds` 承载场景 id，
服务端按 `test_set.kind` 分流并校验（非法 kind → 400），**不新增 `scenarioIds` 字段**。
选用例集/场景时固化成成员快照。

**验收判据**

| # | 判据 | 证据形态 |
|---|---|---|
| 1 | 内容步出现「场景」分区，可多选、计数正确 | 截图 |
| 2 | 2 集 + 5 例 + 2 场景 → 复核步合计 9 项，逐类可展开 | 截图 + 组件断言 |
| 3 | 服务端按 kind 分流：把 `case_set` 的 id 误标为场景 → 400 点名 kind 不符 | 真实请求 |
| 4 | 原子快照：建项目后源集 +3 条 → 已建项目成员数不变 | DB 前后计数 |
| 5 | 两向导 import 同一组件，全选/清空/搜索行为一致 | 代码检查 + 截图 |
| 6 | 反向判据：在 `876da9b` 上 `sectionKeys` 无 `scenario` | 回放日志 |

### FR-v5.17-03 演示对象 purge 覆盖取证【P2】

**描述**：造 1 个 `is_demo=1` 演示项目（2 用例集 / 10 用例 / 1 报告）→ `purge-demo.sh` dry-run 覆盖 13 个对象；
真实项目不出现；前后计数一致；收尾 `--apply` 清到 `is_demo=1` 为 0。
**注意**：本条只验「演示标记」这条链路；**未打标的临时对象清理由 5.18 FR-07 处理**，两者不重叠。

**验收判据**

| # | 判据 | 证据形态 |
|---|---|---|
| 1 | 清单含 13 个对象（逐类计数） | 脚本输出 |
| 2 | dry-run 前后逐表计数一致（零写入） | 前后计数 |
| 3 | 真实项目不出现 | 脚本输出 |
| 4 | `--apply` 后 `is_demo=1` 计数回 0 | DB 查询 |

### FR-v5.17-04 性能读数闭环【P1】

**描述**：`scripts/perf-longlist.mjs` 采「1000 行数据集、每页 100 行」的滚动 fps（≥3 轮）；
`performance.mark/measure` 采 3000 分类展开耗时（≥3 次）。`status` 只能是 PASS/FAIL。

**验收判据**

| # | 判据 | 证据形态 |
|---|---|---|
| 1 | ≥3 轮，每轮 fps/帧数/最差帧/机器信息齐全 | json |
| 2 | `min_fps ≥ 50` → PASS；否则如实 FAIL 并登记 | json + 机检 |
| 3 | 3000 分类展开 P95 ≤ 500ms | json |
| 4 | `perf_longlist.py --selfcheck` 仍判红 0 轮冒充 | 机检输出 |
| 5 | manifest 含行数与 sha256 | manifest 文件 |

### FR-v5.17-05 掩码凭证名【P1】

**描述**：采集历史每行新增 `credentialId` / `credentialMaskedName`；SQL 左连最新 `credential_verification`
取 `credential_id`，再连 `credential.name` 并掩码。**不返回 `secret_ref`、不返回 `spec_json`**。

**验收判据**

| # | 判据 | 证据形态 |
|---|---|---|
| 1 | 凭证 A 采集 → 首行指向 A，名字为掩码形态 | 真实响应 + DB |
| 2 | 换凭证 B → 两条历史分别指向，掩码名不同 | 真实响应 |
| 3 | 无事实 → 两字段 null，界面「未记录」 | 截图 + 断言 |
| 4 | 响应不含 `secretRef` / `secret_ref` / 明文 | 正则扫描 + 六处探针 PASS |
| 5 | 反向判据：`876da9b` 响应无该字段 | 回放日志 |

### FR-v5.17-06 画像 500 台性能达标【P1】

**描述**：造 500 台 `PERF-` 设备（独立压测项目）→ 采 `collect-profiles` P95（≥5 次）；
>800ms 则改「1 次主表 + 2 次分组聚合 + 应用层合并」，**不建物化表**。

**验收判据**

| # | 判据 | 证据形态 |
|---|---|---|
| 1 | 500 台下 P95 ≤ 800ms | 计时 json |
| 2 | 若改 SQL：前后响应逐字段一致 | 两次响应 diff |
| 3 | 既有工程/用例计数前后不变 | 前后计数 |
| 4 | `--purge` 后压测残留 0 | DB 查询 |
| 5 | 500 台不可达 → 如实 FAIL + 登记，不用 13 台推断 | 报告结论 |

### FR-v5.17-07 套件数与深链一级证据【P1】

**描述**：在 `robot_it` 造 R1（单套件）/ R2（多套件）/ R3（含空 `case_key`）三个夹具 run，
使 `suite_count` 落真值；断言「列表套件数 = 详情树一级子节点数」；深链截图 2 张。

**验收判据**

| # | 判据 | 证据形态 |
|---|---|---|
| 1 | R1/R2 的 `suite_count` 非 NULL 且等于一级套件数；**R3（空 `case_key`）必须为 NULL** | DB |
| 2 | 三样本「列表数 = 详情树一级子节点数」逐条相等 | DB + HTTP |
| 3 | 历史 NULL 显示「—」不显示 0 | 截图 + 断言 |
| 4 | 深链自动滚动 + 高亮 | 截图 ×2 |
| 5 | 非法 `suite` 参数 → 可解释提示 | 截图 |
| 6 | `robot_dev` 行数前后不变 | 前后计数 |
