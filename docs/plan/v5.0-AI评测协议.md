## 1. 前置（缺一不可）

1. 大师单独授权真实端点调用与外部服务边界；2. 合规凭据经密钥轮换并只走环境变量；
3. 评测数据脱敏通过 `check_report_sensitive.py`；4. 隔离网络与超时 / 降级策略就绪。

## 2. 黄金集

100 条任务，覆盖参数提取、命令生成、结果判读、失败归因四类，每条含 `case_id` / `input` / `expected_facts` /
`judge_rule`；语料不含凭据、口令、实网配置、用例正文。`input` 与 `expected_facts` 只存哈希与索引，原文另存受控目录。

## 3. 判定规则

| 项 | 判据 |
|---|---|
| 事实一致性 | 逐条比对 `expected_facts`，由独立裁判 J7 复核，不接受模型自评 |
| 超时 / 降级 | 单次超时记 `degraded`，连续三次判 `BLOCKED` 并停止评测 |
| 脱敏 | 响应逐条校验 `keyMasked` 前缀，不对整段响应查 `sk-`（会命中描述文本） |
| 证据 | 原始响应、判定明细、脱敏检查、耗时分布落 `docs/evidence/v5.0.0/ai/` |

## 4. 禁止项

- 不得用 fake CLI 的 20/20 折算真实端点事实一致性；不得把离线契约评测写成「端点达标」。
- 不得把凭据、令牌、prompt 原文写进仓库或证据文件。
