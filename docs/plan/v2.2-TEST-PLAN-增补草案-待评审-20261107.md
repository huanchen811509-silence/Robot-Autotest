## 5. 独立裁判方案（不接受实现方自证）

1. **机检脚本由非实现方复核**：`check_release_docs.py` / `check_md_tables.py` / 新增 metadata 机检步的断言，由大师指定复核人签一行「已看原始输出」；实现方只提供输出，不自行宣布 PASS。
2. **真实链路优先**：TC-v2.2-35 必须是真实 HTTP + 真实 RF，产出 `output.xml` 与 `run_artifact` SHA；合成夹具只能用于 U 层。
3. **反例由第二方构造**：TC-v2.2-29 ~ 34 的输入样本由非实现方提供，避免「自己造一个自己能过的反例」。
4. **人工抽样复核**：813 条追溯（TC-v2.2-33）与判据归一抽样比照，须人工抽 10 条逐条核对源表行，**不接受 AI 自证**（沿用双内核 T4 抽样比对纪律）。
5. **门禁与发版门分离**：本版 Q1–Q8 由机检 + 大师指定复核人判定；**G4 / G5 / G7 / G8 的判定仍归大师**，不因本版 TC 全绿自动推进。
6. **证据形态**：每条 TC 落到「哪个脚本 / 哪个测试类 + 一条命令 + 一个证据文件」；证据 README 含命令原文、原始输出（截取关键行）、判定数值；不写「已验证」而无输出。
