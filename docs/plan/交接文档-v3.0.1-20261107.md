### 3.3 已知取舍与边界（有意为之，勿当缺陷）

| 项 | 边界 | 原因 |
|---|---|---|
| 分片「两节点」 | 进程内假 agent（node 11/12），非物理双机 | 等价性已实测；真实网络分区/时钟漂移未覆盖 |
| 性能基线 | 劣化判据 = 超基线 10% **且** 绝对增量 > 30ms | WSL 宿主 load 3+，15ms 下限会把调度噪声判成回归 |
| 跨轮失败簇 | 禁用重跑 | 合并了多轮用例，拿单轮 runId 重跑会破坏统计口径 |
| 示例用例 | 6 条纯离线 RF 套件 | 证明「能进库、能跑、能出报告」，不证明外部 DUT 场景 |
| 登录「记住密码」 | localStorage 明文 | 内网测试平台自动登录诉求下的选择 |
| `run.node_id` 历史 NULL | 不回填 | 不伪造历史事实 |
