# 契约：用例执行状态与安全级（v5.31.0）

> 日期：2026-11-20 ｜ 作者：学徒 ｜ 上游：PRD `FR-v5.31-01~08`、ADR-0013 §4
> 性质：W81-01 交付物。**本契约是前后端与执行链路的唯一状态口径**；与本文件冲突的实现视为缺陷。

---

## 1. 四个可写字段（谁写 / 谁读）

| 字段 | 表.列 | 取值 | 谁写 | 谁读 |
|---|---|---|---|---|
| 安全级 | `test_case.safety_level` | `L0` / `L1` / `L2` / `LX` | 新建表单、批量定级、导入 | 执行预检、列表筛选、详情 |
| 优先级 | `test_case.priority` | `P0`–`P3` / `NULL` | 新建、批量改、导入归一 | 列表排序/筛选、执行范围 |
| 评审态 | `test_case.review_status` | `draft` / `pending` / `approved` / `rejected` | 提交/评审 | 列表筛选、执行软提示、报告 |
| 用例启停 | `test_case.enabled` | `0` / `1` | 启停（预留） | 列表默认过滤、执行 |

## 2. 两个派生态（只读，不得落库为独立列）

| 派生态 | 由什么算出 | 唯一产出点 |
|---|---|---|
| 脚本绑定态 | `case_script_binding` 行 + `verified` + 内核能力 | `CaseScriptView`（`BOUND_VERIFIED` / `BOUND_UNVERIFIED` / `UNBOUND` / `NOT_APPLICABLE`） |
| 计划状态 | `execution_plan.status` | `PlanStatus`（`ENABLED` / `PAUSED`） |

## 3. 执行预检决策树（唯一裁决点）

```
输入：选中用例集合 + 模式（fake|real）+ 配置 execution.unrated-mode
  │
  ├─ 用例 enabled=0 ────────────────────────► 排除（不计入 N，单独列「已停用」）
  ├─ safety_level=L2 ───────────────────────► 阻断（不论模式，需逐条审批）
  ├─ safety_level=LX 且 unrated-mode=block ─► 阻断（原行为，默认）
  ├─ safety_level=LX 且 unrated-mode=confirm ► 风险项：计入 M，需显式确认
  ├─ 绑定态=UNBOUND ────────────────────────► 阻断（提示补脚本或改绑定）
  ├─ 绑定态=BOUND_UNVERIFIED ───────────────► 软提示（可继续，建议先确认）
  ├─ review_status∈{draft,pending} ─────────► 软提示（计入「未评审 N 条」）
  └─ 其余 ──────────────────────────────────► 放行
```

**不变式**：

1. `L2` 在任何配置下都不可自动放行——`unrated-mode` 只对 `LX` 生效。
2. 阻断项与风险项必须分开返回：阻断决定「能否创建 run」，风险项只决定「确认面板展示什么」。
3. 确认凭据只落审计与 run 元数据，不落 `test_case`。
4. 列表筛选与执行选择使用**同一个参数构造函数**，不允许各拼一套。

## 4. 词表

| 维度 | 合法值 | 非法值处理 |
|---|---|---|
| 安全级 | `L0` `L1` `L2` `LX` | 400 |
| 优先级 | `P0` `P1` `P2` `P3` `NULL` | 400（导入则记 NULL + 报告列「未识别」） |
| 评审态 | `draft` `pending` `approved` `rejected` | 400 |
| 绑定态筛选 | `BOUND_VERIFIED` `BOUND_UNVERIFIED` `UNBOUND` `NOT_APPLICABLE` | 400 |
| 计划状态 | `ENABLED` `PAUSED` | 400 |
| 链路置信度 | `confirmed` `collected` `planned` | 400 |

## 5. 执行侧拦截的错误码

| 场景 | 错误码 | HTTP | 消息要点 |
|---|---|---|---|
| L2 命中 | `SAFETY_LEVEL_BLOCKED` | 403 | 「L2 高危禁止自动执行」 |
| LX 且 block 模式 | `SAFETY_LEVEL_BLOCKED` | 403 | 「未定级按 L2 对待；可批量定级或开启知情确认」 |
| LX 且 confirm 模式、未勾选 | `INVALID_ARGUMENT` | 400 | 「含未定级 N 条，需确认」 |
| 未绑定脚本 | `INVALID_ARGUMENT` | 400 | 「存在未绑定脚本的用例」 |
| 未知筛选键 | `INVALID_ARGUMENT` | 400 | 列出非法键名 |

## 6. 变更流程

改本契约（尤其 §3 决策树）必须同时改：ADR-0013（若涉及安全级）、PRD 对应 FR、本文件、对应 TC。**只改代码不改契约 = 缺陷**。
