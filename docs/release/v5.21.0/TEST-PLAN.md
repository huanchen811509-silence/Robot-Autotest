## 3. 不可降级项（V-1 ~ V-6）

| 编号 | 对应 TC | 内容 | 为什么不可降级 |
|---|---|---|---|
| V-1 | TC-v5.21-01 | `GET /api/roles` = 4 条 | 这是本版一切的前提，少一条就是"角色仍不存在" |
| V-2 | TC-v5.21-07 | 无角色账号能力集 = 最小集 | 放宽就是权限放大，属于安全事故而非体验问题 |
| V-3 | TC-v5.21-12 | viewer 写按钮数 = 0 | 允许留 1 个就说明 `v-can` 没覆盖全 |
| V-4 | TC-v5.21-15 | 受限路由落 403 页 | 否则"按钮藏了但地址栏能进"，等于没做 |
| V-5 | TC-v5.21-20 | 24 格矩阵全 PASS | 只验一个工程等于没验同构 |
| V-6 | TC-v5.21-28 | 角色代码混写计数 = 0 | 混写会让前端判据随机失效，无法回归 |
