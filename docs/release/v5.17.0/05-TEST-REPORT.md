## 3. 本版修掉的 4 个真缺陷（W67-01 取证过程中发现）

| # | 缺陷 | 影响 |
|---|---|---|
| 1 | `purge-demo.sh` 漏统计 `test_set` | 13 个对象里 2 个不在清单 |
| 2 | 脚本只输出计数、不输出对象清单 | 「清单可人工复核」判据无法落地 → 加 `--json` |
| 3 | 有从属数据时 `DELETE FROM project` 报 1451，且已删一半成员关系 | 库进入半删状态，重跑回不去 → 加前置门禁 |
| 4 | 注释指引「走项目删除接口」是死路 | 实测该接口对有内容项目返回 409，只许归档 |
