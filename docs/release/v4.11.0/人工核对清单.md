| B6 | **侧栏二级项可直接复制链接** | 逐个点公共资产 / 模板 / 公共用例下的二级项，看地址栏 | URL 会带上 `?tab=devices`、`?kind=builtin`、`?view=imports`、`?scope=mine`。把该 URL 粘到新标签页打开，**还是这一项、这一项还是亮的**（不会两个都不亮） |
| B7 | **导入预览可以强制重算** | 全局模式 → 公共用例 → 导入记录 → 重新上传一份**已提交过**的文件 | 默认仍提示「本次为回放，不会改数据」；勾上「强制重算」再预览，能看到按当前库重新算出的差异，而**导入记录里那条历史批次的状态与条数不变** |
