## 4. 调研结论（对本版的直接影响）

1. **5.9 必须是「先正口径」的版本**：R1/R2 是同一类问题——**同一个事实有两个来源**（高亮有
   `alsoMatch` 与精确 path 两套；可见性有成员表与 owner 列两套）。不先收成单点，5.10 起的
   向导与权限页都会各自再实现一遍，越往后越难拆。
2. **迁移先行**：`is_demo`、组三表外键、`created_by` 索引三项是 5.9 自己的编译前提，也是
   5.10+ 的数据前提，必须最先进库。
3. **开发/演示隔离贯穿每版**：`is_demo` 不只是 5.9 的活，5.10~5.16 每加一张表都要问一句
   「这张表的演示数据怎么标」。本版只打地基（列 + 清理脚本 + 机检），不追求一次清干净。
