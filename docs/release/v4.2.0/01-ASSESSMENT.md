**文档编号** RA-ASM-420 ｜ **版本** v1.0 ｜ **日期** 2026-11-10

## 1. 前置条件

| 条件 | 本轮现状 | 不满足时怎么办 |
|---|---|---|
| MySQL 8.0 可达（`robot_dev` 与 `robot_it`） | 具备 | 无库只跑非 IT 单测，IT 记 `NOT-RUN` |

| 非生产 SSH 目标 + 已登记 `known_hosts` | **不具备** | 远程采集 `TC-v4.2-09` 记 `NOT-RUN` |
| GitHub 凭据 / `gh` CLI | **不具备** | artifact 下载类 TC 记 `NOT-RUN` |
| 第二空实例 B | **不具备** | 跨实例 round-trip 记 `NOT-RUN` |

## 2. 方案比较

### 2.1 工作区包的格式

| 选项 | 做法 | 取舍 |
|---|---|---|
| A | 单个 `tar.gz` + 内嵌 manifest | 校验要解包后才能做，无法先验后写 |
| B | 单个大 JSON | 二进制/大文件不适合，无法逐文件 `sha` |
| **C（选用）** | 目录树（7 子目录）+ `project.json` + `manifest.json`（逐文件路径 / `sha256` / 字节）+ `members.json` | 可逐文件校验、可 dry-run 预检、可只传单文件 |

### 2.2 签名与验签

| 选项 | 做法 | 结论 |
|---|---|---|
| **A（选用）** | 平台本地 `keyId=server-local-v1` 签名，导入验签 | 满足「篡改必拒」，不依赖外部服务 |
| B | 外部 KMS / HSM | 密钥流水线未定（`G-10`），留待后续 |
| C | 不签名 | 明确不做：无法证明包未被改 |

### 2.3 远程采集通道

| 选项 | 做法 | 结论 |
|---|---|---|
| A | 只做本机采集 | 满足不了远程主机清单需求 |
| **B（选用）** | SSH + `StrictHostKeyChecking=yes` + 显式 `UserKnownHostsFile` + `BatchMode=yes` | 未知主机直接失败，失败原因可解释 |
| C | 关闭指纹校验 | **不做**：等于把「可被中间人替换」写进产品 |

### 2.4 Schema 口径

| 选项 | 做法 | 结论 |
|---|---|---|
| A | `SchemaIT` 与 `db-audit` 各写常量 | 已实证会漂移 |
| **B（选用）** | 单份 `db/schema-contract.json`，两端直读 | 改一处两端同时变；负向样本仍判红 |

### 2.5 CI 质量门

| 选项 | 做法 | 结论 |
|---|---|---|
| A | 只构建，单测留在开发机 | 合并前无红灯 |
| **B（选用）** | 构建前跑后端非 IT 全量与前端单测，不连 MySQL、不启 CDP | 无库环境可红可绿，`DB_PASSWORD` 不入 workflow |

## 3. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 导入半途失败留脏数据 | 目标项目被写坏 | 单事务 + 中途失败整批回滚 |
| 路径穿越 / 控制字符 | 写到工作区之外 | 白名单校验，`..`、绝对路径、非白名单扩展名全拒 |
| 包被篡改 | 引入不可信内容 | `manifest` 逐文件 `sha256` + HMAC，任一不符即拒 |
| 口令进 `argv` | 进程列表泄露 | 口令只进 `SSHPASS` 环境变量，`argv` 只有 `sshpass -e ssh …` |
| 私钥落盘残留 | 密钥泄露 | 临时文件 `0600`，`finally` 必删 |
| append-only 强制 `created_at` | 真库必然判红 | 契约显式「`created_at` 或业务时间锚点二选一且互斥」 |
| `-Dgroups=it` 假通过 | 0 用例仍绿 | 统一 `-Pit` + `DB_NAME=robot_it`，写进类注释 |
| 门禁第 6 步表格阻断 | 门禁无法全绿 | `WorkspaceView.vue` 改 `DataTable` 壳，不扩白名单 |

## 4. 结论与不做的事

**做**：`FR-v4.0-01` ～ `05`、`FR-v4.1-01` ～ `05`、`FR-v4.2-01` ～ `04`，共 14 条需求（清单见 [PRD.md](./PRD.md) §2）。

**不做**：

- 不自动 `ssh-keyscan` 信任未知主机，也不提供「跳过指纹校验」开关。
- 不提供 `sudo` / `su` / `doas` 提权采集；命令命中即拒且不启动进程。
- 不做跨实例自动合并 / 冲突自动裁决（B 实例未就绪）。
- 不发布公开 Release，不改仓库名、`artifactId`、npm `name`、包名与库名。
- 不为通过放宽 `SchemaIT` 的 `_it` 后缀守卫，不把 `WorkspaceView.vue` 加进表格白名单。
- 不把 `NOT-RUN` 记成 `PASS`；无证据项保持 `NOT-RUN` 并写明补齐方法。
