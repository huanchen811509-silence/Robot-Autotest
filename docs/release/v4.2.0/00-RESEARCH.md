# v4.2.0 需求调研（RA-RES-420）

**文档编号** RA-RES-420 ｜ **版本** v1.0 ｜ **日期** 2026-11-10 ｜ **对应计划** `docs/plan/v4.x-总体演进-*`

> 本版是 4.0.0 / 4.1.0 / 4.2.0 三个批次的**一次性落号**：`VERSION` 由 `3.11.0` 直接到 `4.2.0`，
> 十九个工作包（`W40-00` … `W42-05`）在一条版本线上收口。调研只回答「起点在哪、缺口在哪、哪些判不了」。

## 1. 三个批次的真实起点

| 批次 | 主题 | 起点问题 | 结论依据 |
|---|---|---|---|
| `4.0.0` | 交互基座 + 合规硬伤 + 可回滚升级 | 命令脱敏漏 `-u user:pass`；顶栏各入口浮层范式不一；折叠态留白偏窄；升级无回滚演练 | `EW40-01` ～ `EW40-06` |
| `4.1.0` | 项目工作区目录化 + 创建向导 | 项目只能在库里复制，无法整包导出/导入；把一套项目搬到另一实例只能手工 SQL | `EW41-01` ～ `EW41-07` |
| `4.2.0` | 工程/运维遗留 | CI 只构建不跑单测；`SchemaIT` 与 `db-audit` 各自硬编码表数；远程主机清单只能手抄 | `EW42-00` ～ `EW42-05` |

## 2. 已有能力与缺口

| 能力 | 现状 [已核实] | 缺口 |
|---|---|---|
| 凭据存储 | AES-256-GCM 凭据表 + `CREDENTIAL:USE` 授权 + `credential.use` 审计 | 无（远程采集直接复用，不新增密钥体系） |
| 审计 | 多数表 append-only | `alert_event` / `archived_run` / `release_record` 无 `created_at`，时间锚点是 `detected_at` / `archived_at` / `deployed_at` |
| 迁移 | Flyway 至 `V11_27`，88 张业务表 | 工作区新表需 `V11_28`，且必须附 `down` |
| Schema 判据 | `SchemaIT` 与 `scripts/db-audit.sh` 各自写常量 | 表数/豁免集合会漂移，改一处另一处不变仍绿 |
| CI | `delivery.yml` 只做构建与打包 | 缺「没有 MySQL 也能红/绿」的前置质量门 |
| 主机采集 | 本机 10 类只读命令可用 | 远程主机无通道；`HostInventoryService` 只走本机执行器 |
| 项目交付 | 库内项目 + 报告导出 | 无整项目工作区包，无逐文件 `sha256`，无导入预检 |

## 3. 影响验收的环境事实

| 事实 [已核实] | 影响 | 应对 |
|---|---|---|
| 本机无 `gh`、无 `actionlint` | `TC-v4.2-03/04/12` 的 run/artifact 端到端无法执行 | 如实记 `NOT-RUN`，不拿 YAML 可解析冒充通过 |
| 无受控非生产 SSH 目标与已登记 `known_hosts` | `TC-v4.2-09` 远程采集无法取证 | 记 `NOT-RUN`；平台刻意不做 `ssh-keyscan` 自动信任 |
| 无第二个空实例 B | `TC-v4.1-20/21` 跨实例 round-trip 无法取证 | 记 `NOT-RUN`，不拿同实例两次导入冒充 |
| 本机无 `nvidia-smi` | 本机采集 `PARTIAL 9/10` | 写「未采集到 + 原因」，不填 `0` / `-` 占位 |
| Chrome CDP 非持久化 | UI 探针偶发不可用 | 复测前 `curl :9222/json/version`，不可用即 `NOT-RUN` |
| `axe-core` 未安装 | 无障碍扫描只能手写判据 | 降级并显式标注，不声称已做自动无障碍扫描 |
| 默认 Maven profile `excludedGroups=it` | `-Dgroups=it` 会跑 0 用例仍 `BUILD SUCCESS` | 统一用 `mvn -o -B -Pit test -Dtest=XxxIT` |

## 4. 调研结论

1. **三批可一次收口**：4.0 的交互与升级、4.1 的工作区、4.2 的工程门都只增不改既有 API 路径，适合一条版本线落号到 `4.2.0`。
2. **工作区包必须可逐文件校验**：`manifest.json` 记路径 / `sha256` / 字节数，导入先 dry-run，默认 `skip`。
3. **远程采集的判据是「没采到必须写原因」**：不允许 `未知` / `-` / `0` 占位，失败与成功都落审计。
4. **判不了就写判不了**：缺口逐条转 `NOT-RUN` 并写明由什么补，不用单测或本机读数替代真机证据。
5. **不做的事**见 [01-ASSESSMENT.md](./01-ASSESSMENT.md) §4。
