**文档编号** RA-TP-420 ｜ **版本** v1.0 ｜ **日期** 2026-11-10 ｜ **用例总数** 70（27 + 26 + 17）

## 1. 取证策略

三层证据互不替代：

| 层 | 手段 | 能证明 | 不能证明 |
|---|---|---|---|
| 静态与单测 | `mvn -o -B test`、`npm run test:unit`、`npm run build` | 代码语义、组件逻辑、类型与构建 | 真库、真浏览器、真网络 |
| 契约与真库 | `workspace-contract.sh`、`SchemaIT`、`db-audit.sh` | 真实读写、权限矩阵、事务与迁移 | 界面表现 |
| 真浏览器 | CDP 探针（`chrome --remote-debugging-port=9222`） | 浮层矩形、焦点、点击穿透、无写请求 | 后端语义 |

判不了的写 `NOT-RUN`，并写明补齐方法；不允许用上一层的通过替代下一层的缺口。

## 5. 已知取证缺口

| 缺口 | 受影响用例 | 补齐方法 |
|---|---|---|
| 无 `gh` / `actionlint` / GitHub 授权 | `TC-v4.2-03/04/12` | 在有授权的环境跑 `gh run view` / `gh run download` 并归档日志 |

| 无第二空实例 B | `TC-v4.1-20/21` | 起空库实例后做 A → B round-trip |
| `axe-core` 未安装 | `TC-v4.0-24` | 安装 `axe-core` 后跑自动扫描，替换手写判据 |
| CDP 非持久化 | 全部 UI 探针 | 复测前 `curl :9222/json/version`，不可用即 `NOT-RUN` |
| 无 GPU / `nvidia-smi` | 本机采集项 | 在有 GPU 的机器补，采集侧已写「未采集到 + 原因」 |

## 6. 横向回归与放行

- 横向回归：后端全量单测（无库可跑）、前端 vitest、`vue-tsc`、`vite build`、i18n 键集。
- 门禁：32 步全部 PASS，`--selfcheck` `FAILS=0`。
- 发布机检：`check_release_docs.py` `FAIL 0 / WARN 0`；`check_version_consistency.py` 六项一致。
- 放行：`FAIL` 阻断；`NOT-RUN` 与 `PARTIAL` 逐条可见，不折算为通过。
