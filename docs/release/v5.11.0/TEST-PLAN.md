## 1. 执行方式分类

| 代号 | 含义 | 能证明什么 | 不能证明什么 |
|---|---|---|---|
| `UT` | 后端/前端单测 | 逻辑分支正确 | 真实请求能通、界面能看见 |
| `MECH` | 机检脚本（带 `--self-test`） | 规则被守住且能判红 | 业务语义对不对 |
| `HTTP` | 真实服务请求 | 契约、错误码、真实数据 | 界面渲染 |
| `UI` | 真实浏览器（CDP/人工） | 用户能看见、能点 | 后端边界 |
| `DOM` | 页面内测量（`clientWidth`、实例数、`aria-current`） | 布局与结构事实 | 观感 |
| `DB` | 直连数据库读数 | 落库事实 | 链路是否被调用 |
| `PERF` | 帧率与耗时测量 | 性能不回退 | 功能正确性 |
| `REPLAY` | 在 v5.8 收口 commit 上回放 | 缺陷确实存在且判据能抓到 | 修复是否完整 |

**放行口径**：P0 条目（FR-01/02/03/04/05）必须至少拿到 `UI` 或 `DOM` 或 `DB` 一级证据；只有 `UT` 的条目不得计为达成。
**「幂等」是本版核心不变量**：TC-17 ~ TC-21 必须包含一次「注入假列名判红」的自检，否则幂等只是口号。

## 5. 不可用推断补齐的条目（执行纪律）

| 情形 | 处理 |
|---|---|
| 视口不是 1440×900 | 一律重测；截图必须带视口记录，**不许**用其他分辨率冒充 |
| 无 RF 用例样本 | 用真实 RF 项目造；造不出则 TC-25 标「未执行」，不得以「代码里写了不适用」计为达成 |
| `test_case_step` 无历史数据 | 造 3 步样本；仍无则详情显示「无步骤记录」，但**不许**退回「源表无此列」 |
| 平台集副本造不出来 | 用真实「从平台集复制」功能生成；禁用 SQL 直插冒充（`source_asset_id` 语义会失真） |
| 幂等单测的映射表写成通配 | 视为未达成：必须能注入假列名判红 |
