## 2. 关键取舍（D-1 ~ D-4）

| # | 取舍 | 理由 | 复核点 |
|---|---|---|---|
| D-1 | 详情用**列表内停靠**，不用抽屉/弹窗 | 弹窗遮表格，用户比对时要有两处上下文；抽屉同理。停靠区随表格同宽，滚动不外跳 | TC-01~06 |
| D-2 | 文件名**只由后端算** | 前端 `split('/')` 一次就会三处漂移（R-5 的教训）；`CaseScriptLink` 只显示与复制 | TC-22、TC-27、TC-28 |
| D-3 | RF 用例显示「不适用 + 原因」，**不做模糊匹配** | 猜出来的路径比没有更危险：用户会照着它去找文件，找不到就以为脚本丢了 | TC-25 |
| D-4 | 幂等映射表**禁止通配**，没有来源就必须写 `computedFrom` 或 `reason` | 一旦允许「默认同名自动匹配」，表就退化成万能表，注入假列名也不会红 | TC-17、TC-21 |

## 3. 风险与缓解

| # | 风险 | 缓解 | 落点 |
|---|---|---|---|
| R1 | 详情内联后列表变长，用户找不到表格 | 首次展开 `scrollIntoView({block:'nearest'})`，只滚动「最近」而不是把页面拉到底 | `DetailDock.vue` + TC-01 |
| R2 | 删路由造成死链 | 全仓 grep + `router/deprecated.spec.ts` 断言 `getRoutes()` 不含三条路由，且导航无叶子指向被删前缀 | TC-14、TC-15、TC-39 |
| R3 | `test_case_step` 历史数据缺步骤 | 详情区分「没有步骤记录」（`noSteps`）与「字段没有值」（`emptyValue`），不混用一句「源表无此列」 | TC-18、TC-19 |
| R4 | 脚本 join 让列表变慢 | 一页一次 `IN` 批量查（避免 N+1），按 `(project_id, case_id, kernel)` 唯一键 | `CaseScriptLookup` |
| R5 | 幂等单测形同虚设 | 6 条反证（假列名 / 漏登记 / 无来源计算列 / 不存在的 DTO 字段 / 无理由操作列 / 重复列） | TC-17 |
| R6 | 注解贴错位置（**本轮真实发生**） | 只读方法不加 `@Audited`；插入新方法后必须跑 `AuditAspectTest` | `05-backend_test` 已判红并修复 |
