## 1. 一句话定位

让工作助手**用得顺手**：宽度随手调、助手和模型自己选、输入输出不再挤在一条小框里。

## 2. 范围

**做**：宽度可调（推挤 + 拖拽 + 键盘 + 档位）、窄屏悬浮跟随、Agent/模型选择与按次覆盖、输入输出放大、失效回落明示。
**不做**：全屏模式、会话级偏好、默认开启真实 CLI、模型清单服务端拉取、抽屉内配凭据（依据见 `01-ASSESSMENT.md` §1）。

---

## 3. 功能需求与验收判据

### FR-v2.6-01 抽屉宽度在 340–760 内可调

**要什么**：宽度真的改变布局，不只是一个显示用的数字；鼠标、键盘、按钮三条路径都能调；刷新后记得住。

**判据**：
1. 拖动左缘手柄时，`.app-shell` 的第三列跟随变化（改的是 CSS 变量 `--ai-drawer-w`）；
2. 任何路径的设置值都被钳制到 `[340, 760]`，越界输入不产生越界布局；
3. 档位按钮按 340 → 420 → 520 → 760 循环，到顶不再增长；
4. 方向键左/右各 20px，Home/End 直达两端；
5. 值写入 `localStorage`，刷新后恢复；存量越界值（如 280）读取时被收进边界。

### FR-v2.6-02 窄屏悬浮态跟随宽度且不超视口

**要什么**：≤999px 时抽屉本来就是悬浮，宽度也要跟随设置，但绝不能超出视口。

**判据**：
1. `≤999px` 时抽屉仍为 `position: fixed`（不挤压主区）；
2. 其 `width` 为 `var(--ai-drawer-w)`，同时 `max-width: 100%`；
3. 悬浮态下拖拽不产生「比视口还宽」的布局。

### FR-v2.6-03 可选 Agent 与模型，且按次生效

**要什么**：抽屉里两个下拉，一个选助手、一个选模型；选完这一轮就用它，不是只存起来不用。

**判据**：
1. `GET /api/ai/agents` 返回本机**已安装**且未被管理员关闭的 agent（含 name / models / defaultModel），
   **不返回** baseUrl / apiKeyEnc / keyMasked / hasKey 任一字段；
2. 该接口只做项目访问校验，**不要求管理员**；
3. 选中的 agent 与模型随 `POST /api/ai/chat` 的 `cli` / `model` 字段下发，并真正进入子进程环境与 argv；
4. 不给 `cli` / `model` 时行为与 v2.5 完全一致（首选 agent + 设置页已保存模型）；
5. 换 agent 时模型清空，回到「默认模型」。

### FR-v2.6-04 输入与输出区放大

**要什么**：输出区撑满抽屉剩余高度；输入是多行、能长高；字号可读。

**判据**：
1. 抽屉为竖向弹性布局，历史区 `flex: 1 1 auto; min-height: 0; overflow-y: auto`，
   **不再有** `max-height: 240px` 这类硬上限；
2. 输入为 `<textarea>`（非单行 input），初始约 3 行、随内容长高、封顶 240px 后内部滚动；
3. Enter 发送、Shift+Enter 换行；中文输入法组合期（`isComposing`）不误发；
4. 正文字号 ≥ 13px。

### FR-v2.6-05 选中项失效时回落并明示

**要什么**：本地偏好是上一轮存的，机器状态会变。选中的 agent 被卸载/禁用时，别报错把面板弄死，
也别偷偷换一个装没事。

**判据**：
1. 后端检测到所选 agent 不可用时回落到首选可用 agent，响应里带 `requestedCli` 与原值、`cliFallback=true`；
2. 前端在对话框上方显示「所选助手当前不可用，已回落到 X」；
3. 前端加载清单时若发现本地偏好已不在清单里，清掉偏好回到「自动」。

## 4. 非功能要求

| 项 | 要求 |
|---|---|
| 安全 | 清单接口不含端点与任何凭据形态；对话接口仍走项目访问校验 |
| 兼容 | 不给 `cli`/`model` 的老调用方行为不变；`ChatRequest` 缺字段按 null 绑定 |
| 可达性 | 拖拽手柄 `role="separator"`、可聚焦、有 `aria-valuenow/min/max`、支持方向键与 Home/End |
| 样式纪律 | 新增 px 必须命中 `tools/px-allow.txt`；不写硬编码色值；CSS 变量必须在 `theme.css` 有声明 |
| 不降级验证 | 「选择生效」必须用真实模型调用证明，不接受「下拉里有了」当证据 |
