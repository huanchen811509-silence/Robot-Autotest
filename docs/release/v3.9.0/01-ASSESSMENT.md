## 3. 不做什么（本次明确排除）

1. **不做**命令的**复跑**（一键重放）：需要 DUT 选择、二次确认、审计留痕，属 v3.12-03。
2. **不做**多命令全量清单：一本版只保留用例首条命令，其余丢弃（可见于 `keywordHitStats`）。
3. **不引入**自定义下拉组件（ADR-39-01）：原生 `select` + 主题令牌已满足可读性，换组件
   会带来焦点管理、键盘、SSR 三类新问题。
4. **不改** pytest 产物中 `kind=output_xml` 的错误登记（L-39-01）：读侧已按文件名判定，
   改动属夹具清理，排 v3.10。
5. **不动**周报（FR-v3.12-01）与资产漂移（FR-v3.12-02）。

## 4. 被实测推翻的假设

| 假设（调研阶段） | 实测结果 | 处置 |
|---|---|---|
| 「模板页 1.8 屏，收进折叠即可 ≤1 屏」 | 测量对象错（`documentElement` 恒等视口）；真实 **2.4 屏** | 改为按 `.app-main.scrollHeight` 测量，重做压缩方案（双列紧凑行 + 标题编辑器默认收起） |
| 「命令能从 RF 关键字自身消息取到」 | 真实 run 实测 3/3 得到 `NONE`：命令在**子关键字 `Log`** 的消息上 | 提取器改为命中白名单后前序遍历子树 |
| 「pytest 侧只要补命令列，日志本来就有」 | pytest 日志抽屉恒为空（`log_offset=-1`），PRD Q2-7 的缺陷真实存在 | 新增 `PytestLogPersister` + `JsonlLogReader`，入库时摊平日志 |
| 「放开页大小即可填满列表」 | 页面根容器非 flex，`.page` 无法撑高，空白照旧 | 同时改 `.app-body` 为 flex 列 + DataTable `flex-height` |
