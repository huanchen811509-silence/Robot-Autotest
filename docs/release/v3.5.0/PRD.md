## 1. 范围与退出标准

本版承接母文档 §5 的 10 条 FR，全部为存量打磨（不加新功能域）。退出标准：
P0 全达成、P1 达成或有降级说明与授权人、P2 有去向；十层测试按版本重点执行并留证；
**文档回写完成**；既有发版门禁状态单独记录，3.5+ 验收不替代 G4/G5/G7/G8 与 G6 观察钟。

## 3. 非功能要求

沿用母文档 §7 NFR-v3.5-01..09：性能（API p95 ≤150ms / p99 ≤300ms；LCP ≤2.5s / INP ≤200ms / CLS ≤0.1）、
可靠性（工作时段 ≥99.5%）、安全性（高危 0、凭据不进日志）、可维护性（diff 覆盖 ≥70%、契约漂移 0）、
兼容性（四条冻结契约）、可观测、隐私、AI 可信、可回滚。

## 4. 数据模型与接口影响

本版不新增业务表、不改执行结果语义与报告口径；如涉迁移只追加且带 down。体验事件走服务端聚合，
字段最小化、默认关闭，不落凭据 / 用例正文 / 实网配置。

## 5. 明确不做

见母文档 §3.4 与本报告 `01-ASSESSMENT.md` §3；v3.8.0 现场与 UAT 不在本版范围。
