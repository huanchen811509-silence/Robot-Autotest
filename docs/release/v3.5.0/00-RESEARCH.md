## 3. 现有系统能力边界与不可改之处

- 双内核执行链（RF 7.5 + pytest 双内核）、`run.kernel` 快照、`.robot` / `output.xml` / 产物目录 / CI 回调四条冻结契约不改。
- `output.xml` metadata 十项（必填 6）键大写、值 ≤40 字符、不放凭据；`RUN_ID` 键名不可改。
- 迁移只追加，已应用迁移 checksum 不可变；单主机 `:8001` + `:8081` 部署形态不变；不引入 Redis / MQ / 外部 APM。
- 发版门禁 G4/G5/G7/G8 未判、G6 七日观察钟未启动；本轮验收不替代 G 门判定。
