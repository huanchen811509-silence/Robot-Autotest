## 3. 明确「不做」的清单

1. 不做微服务化 / 分布式重写，不引入 Redis、MQ、独立搜索集群、外部 APM。
2. 不重做主题、不替换双内核执行链、不改 `output.xml` 十项 metadata 与对外字段白名单。
3. 不承诺真实 CI Runner 自动注册、真实 DUT 全量自动化、G 门判定与正式发版。
4. 不把 AI 升级为自主执行代理；不自动改代码、自动提交、自动跑真机。
5. 不降低既有门禁阈值、不删步骤、不改测试迁就实现；不伪造现场结果。
6. 不擅自开启归档（`enabled=false`）、不擅自调整准入与 AI 配额默认值。
7. v3.8.0 现场与 UAT 批次本轮不启动（P2 候选，需大师单独授权）。
