# v5.16.0 开发计划（DEV-PLAN）：运维管理 —— 先有任务化，再谈界面化

> 流程位置：④ 开发计划。**无开发计划不许开工编码**。
> 上游：`PRD.md`（12 FR + 8 NFR）、`05-环境拓扑与运维评估.md` §二、白泽调研报告 §8.5/§8.6。
> 本文件给 WBS 编号、改动面与**可复制的验收命令**；不给「大约几天」，只给依赖关系与可独立验收的边界。
> **D-7 未定**：菜单归属方案 A（新增一级「运维」，6→7 组）为 PRD 默认；W66-04 开工前须大师拍板，选 B 则只改导航与 W66-04 的入口布置，其余 WBS 不变。

## 1. 波次总览

| 波次 | 名称 | WBS | 可独立验收 | 与其他波关系 |
|---|---|---|---|---|
| W1 | 任务化框架 | W66-01 ~ W66-03 | 是 | 必须最先（所有长动作都挂它） |
| W2 | 控制台骨架 | W66-04 ~ W66-05 | 是 | 依赖 W1（骨架里就有任务历史） |
| W3 | 健康与只读事实 | W66-06 ~ W66-07 | 是 | 依赖 W2（页面容器）；与 W4 并行 |
| W4 | 备份与演练 | W66-08 ~ W66-11 | 是 | 依赖 W1（任务）、W2 |
| W5 | 归档与维护页 | W66-12 ~ W66-13 | 是 | 依赖 W2 |
| W6 | 升级预检与演练 | W66-14 ~ W66-16 | 是 | 依赖 W4（复用演练与备份护栏）、W1 |
| W7 | 护栏与审计 | W66-17 ~ W66-19 | 是 | 依赖 W4/W6（动作存在才谈护栏） |
| W8 | 收口 | W66-20 ~ W66-21 | 否（最终波） | 依赖 W1 ~ W7 全部出口判据 |

**并行纪律**：W1 硬前置；W3/W5 可与 W4 并行；W6 必须在 W4 之后（升级演练要复用恢复演练）；
W7 必须在 W4/W6 之后（护栏是给真实动作上的）。
**本版迁移 1 支**（`V11_78` `ops_task`）。

**两条不可越过的线**（PRD §5 FR-10）：
1. **恢复只到 `_it` 库**：非 `_it` 一律拒，恢复生产库只显示 CLI 命令；
2. **破坏性动作零默认**：无 `--apply` / 无二次确认时写入行数 = 0。
这两条是本版唯一会「用界面动生产数据」的方向，任何实现便利都不能越过。

## 2. W1 任务化框架（W66-01 ~ W66-03）

### W66-01 `V11_78` `ops_task`

| 项 | 内容 |
|---|---|
| 目标 | `ops_task(id, type, operator, params_json, phase, log, result, started_at, finished_at, status)` + 索引（`type`、`started_at`、`status`） |
| 改动面 | 迁移两支；`status` 取值 `RUNNING/SUCCESS/FAIL/ABORTED` |
| 出口判据 | ① 空库/既有库各跑一次；② down 可回滚；③ `status` 与 `phase` 有默认值与 NOT NULL 约束 |
| 验证命令 | `psql "$DB_URL" -c "\d ops_task"` |
| 依赖 | — |

### W66-02 异步执行器与阶段进度

| 项 | 内容 |
|---|---|
| 目标 | 任何 >3s 动作建 `ops_task` 并异步执行；解析脚本 `STEP n/10 name OK\|FAIL` 结构化输出更新 `phase`；2s 内返回 `taskId` |
| 改动面 | `OpsTaskService`（提交/执行/进度）、脚本输出解析器、Controller（提交与查询） |
| 出口判据 | ① 触发备份 2s 内返回 `taskId`；② `phase` 随脚本输出推进（至少 3 个阶段可见）；③ 失败时 `result` 含失败阶段与人话 |
| 验证命令 | `curl -s -X POST "$API/api/ops/backup" -d '{}' \| jq '.taskId'` 后轮询 `GET /api/ops/tasks/{id}` |
| 依赖 | W66-01 |

### W66-03 并发互斥与超时判定

| 项 | 内容 |
|---|---|
| 目标 | 同类型任务并发只允许一个（第二个返回 409 并提示「已有同类任务在运行」）；进程被杀后超时判 `ABORTED`（不永久 `RUNNING`） |
| 改动面 | 互斥锁/唯一约束 + 超时扫描（定时任务或启动时回收）+ 单测 |
| 出口判据 | ① 并发触发第二个被拒；② 杀掉执行进程 → 超时后状态 `ABORTED`；③ 单测覆盖两种路径 |
| 验证命令 | `cd backend && mvn -o -B -Dtest=OpsTaskConcurrencyTest test` |
| 依赖 | W66-02 |

## 11. 风险与应对

|---|---|---|
| R1 | 界面化把 `install.sh`/`uninstall.sh` 的终端护栏拆掉 | L4 明确不做可执行入口，只展示命令（W66-16 判据 3 代码检查） |
