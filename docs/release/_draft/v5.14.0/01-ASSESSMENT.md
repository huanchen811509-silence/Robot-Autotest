## 2. 关键取舍（D-1 ~ D-7）

| # | 取舍 | 理由 | 复核点 |
|---|---|---|---|
| D-1 | 套件数**只留一份切分函数**，`ReportTreeService` 与入库都调它 | R-13：另写「pytest 按 `.`」必然与树打架 | `CaseKeySplitTest` 同一 `case_key` 集合两处前缀数相等 |
| D-2 | 预览**以冻结快照为准**，新增只读 HTML 通道而非复用 `render` Map | R-9：`render` 只给字段；冻结后模板变更不得影响预览 | hash 比对 + `sandbox` 不含 `allow-same-origin` |
| D-3 | 迁移**只追加**，从 `V11_73` 起并配 `.down.sql` | R-1：`V11_69~72` 从未落文件，跳号是编号约定 | 迁移演练 + `db-audit` 表数不变 |
| D-4 | 「已交付能力」一律**降级为回归项**，不重写 | R-7/R-8/R-10：重写会形成第二套真值链 | 5.9 批量删 / 5.7 打印页既有回归逐条绿 |
| D-5 | 对外口径改名**只动 i18n 与展示层**，不动表名 / 代码命名 | 草案硬约束 1；改表名要迁移 + 契约重生成，收益为零 | `menu.*` / 页面标题 / 跳转按钮三处一致 |
| D-6 | 模板 `kernel` 用 `robot/pytest/any`，白名单按维度分组但**仍只有一个真源类** | R-12：现有 21 项白名单是单一集合，拆成两份会漂移 | `ReportFieldWhitelistTest` 扩断言 |
| D-7 | 断言 `templateId` 改为断言 `TemplateRef` | R-16：`test_report` 无该列，硬加与「只加 1 列」冲突 | `GET /api/test-reports/{id}/template` |
