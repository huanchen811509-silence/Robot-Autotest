# v5.18.0 评估报告：缺口闭合（二）建设与清场

> 流程位置：② 评估报告。上游：`00-RESEARCH.md`、`../v5.17.0/01-ASSESSMENT.md`。

## 1. 目标与范围

把 5.17 未覆盖的 6 项（导入向导、行数收敛、拓扑图例、规划源、探针包、运维真机）
做出来，并在收口时**把 5.8~5.18 开发期留下的临时账号与临时项目清干净**。

## 2. 可行性与风险

| 项 | 判定 | 依据 | 主要风险 |
|---|---|---|---|
| 导入五步向导 | 可行 | 后端 preview 结构稳定，只需加可选 `mapping` 与三数 | 映射错列会静默写错 → 强制前 3 行样例 + 提交前二次确认 |
| 行数收敛到 2200 | 可行 | 列定义与编辑状态机与取数无耦合，可整体外移 | 抽组件导致回归减少 → 用例数逐条对齐基线 |
| 拓扑图例 | 可行 | `link` 已有 confidence/source，只缺边列表接口 | 计数口径混淆（冲突不是第四类边）→ 分开 `kindCounts` 与 `overridden` |
| 规划源 | 可行 | `topology_node` 表已存在，零迁移 | 孤立节点不出图 → 单列 `plannedNodes` |
| 探针包三套 | 可行 | 配置化机制已在（V11_76） | 命令白名单受门禁 29 约束 → 新建目录层 |
| 运维真机 | 可行（需授权） | 三个脚本自包含、自带还原 | 误伤生产库 → 双闸 + 库名白名单 + 前后行数比对 |
| 清场 | 可行（需授权） | 清单驱动 + 备份 + 多轮解外键 | 误删真实对象 → 三信号 + 保留清单二次校验 |

## 3. 前置条件

1. 后端可重启（systemd user 服务），迁移用 `scripts/db-migrate.sh`（应用启动不跑迁移）。
2. 当日备份可写（`backups/`）且 `.sha256` 可读。
3. `robot_it` 可写（恢复到该库，演练后还原）。
4. 大师逐次授权破坏性动作（备份 `--apply`、恢复演练、清场 `--apply`）。
5. 无浏览器环境接受「截图 → 组件断言」的明示降级。

## 4. 不做什么

- 不把行数硬压到 1530（D-2 第一台阶 2200）；
- 不删 `demo` / `demo-pytest`（大师拍板保留）；
- 不删 `qa-e2e-*` 与 `qa-e2e-fixture`（探针与门禁在用）；
- 不用 Linux 包冒充交换机/BMC 包；
- 不按名字匹配删数据；
- 不新增菜单、不改主题。

## 5. 结论

七条 FR 全部可判定、可实现。**清场是 P0**：它不达成，本版视为未完成。
