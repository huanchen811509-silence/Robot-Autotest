## 4. 证据与自证要求

1. 每条 TC 必须有可打开产物（截图 / JSON / PDF / 日志），不接受口述；
2. **断言脚本必须含负向自证**：至少 1 条用例在改动前应判红（尤其 TC-09/10/11、TC-16、TC-32），否则视同未测；
3. PDF 类证据用文本提取校验（不只截图），确认中文可读、无乱码；
4. 证据目录：`docs/evidence/v5.23.0/<WBS 或 TC 组>/`。
