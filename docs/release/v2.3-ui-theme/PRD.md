## 4. 这一版改了什么（用户视角）

| 原来 | 现在 |
|---|---|
| 侧栏 8 组，其中「报告」明明是叶子却当分组用，`/test-reports` 没有任何菜单入口 | 7 组；执行与报告合并为 6 项（运行 3 + 报告 3，一条分区线）；`/test-reports` 有了唯一入口 |
| 工作台只看一个项目，换项目要去别处 | `/workbench` 卡牌总览，一次请求出全部项目，可就地切项目 |
| 顶栏按钮高度 27/23px 混排、项目下拉没有自己的样式（借用语言下拉） | 统一 28px 栅格、四段排序、3 条分隔线、项目选择器独立造型 |
| 主题按钮在 `system` 下点了「看起来没反应」 | 二态翻转，取当前**已生效**主题的反面；`system` 收进外观对话框 |
| 滚动条全仓 0 处自定义 | 5 类容器统一 8px 细条，打印页不受影响 |
