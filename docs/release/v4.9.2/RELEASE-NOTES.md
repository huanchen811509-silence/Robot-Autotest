# v4.9.2 发布说明

发布日期：2026-11-10
版本号：`4.9.2`（GA）

## 本次交付

本版把 4.4.0–4.9.0 六个迭代合并为一次可发布 GA：

- **权限与成员治理**：多角色并集、批量成员、服务端编码建议与改码。
- **双模式**：项目模式 / 全局模式；平台项目承载公共库；`/g/**` 命名空间。
- **公共用例库**：分类、三层幂等导入、固定 14 列导出、批次与错误报告。
- **公共资产库**：分节解析、业务键 upsert、软失效、引用计数删除保护、凭据掩码。
- **模板中心**：持久化、内置模板、引用型内容、向导内容步。
- **存量同步**：预览、五态差异、冲突三分支、整单回滚、本地覆盖、定时预览默认关闭。
- **优化**：i18n 全量校验、错误码 + traceId、空 / 错 / 载态补齐。

## 升级步骤

1. 备份数据库；
2. 启动新版本，Flyway 自动执行 `V11_30`–`V11_37`；
3. 打开「系统设置 → 关于」确认版本为 `4.9.2`；
4. 打开「版本迭代」确认 `v4.9.2-ga` 为当前版本。

## 回退

1. 停服并回退应用镜像 / jar；
2. 按 `docs/evidence/v4.9.2/migration-drill-V11_30-37.sh` 的倒序部分执行 down 脚本；
3. 恢复备份（如已在生产写入公共库数据）。

## 验证要点

- 公共用例导入同一文件两次：第二次应提示回放，不新增批次；
- 被项目引用的公共资产删除应返回 409；
- 存量同步预览不应产生任何用例写入；
- 任一接口报错时，错误提示应带 traceId。
