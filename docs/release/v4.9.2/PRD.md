# v4.9.2 GA 需求与验收

- 版本：`4.9.2`
- 需求基线：[v4.4–v4.9 合并 PRD](file:///E:/workspace/自动化测试/Robot-Autotest/docs/plan/v4.4-v4.9-软件迭代开发PRD-20261110.md)
- 本版定位：4.4.0–4.9.0 六个迭代的收尾 GA，不引入新的业务范围。

## 范围

1. 权限与成员治理（4.4）：多角色并集、批量成员、服务端编码建议、改码。
2. 双模式与品牌（4.5）：项目 / 全局模式、平台项目、`/g/**` 命名空间、顶栏与账户菜单。
3. 公共用例库（4.6）：分类、三层幂等导入、反向导出、批次与错误报告。
4. 公共资产库（4.7）：分节解析、软失效、引用计数删除保护、凭据掩码。
5. 模板中心（4.8）：模板持久化、引用型内容、向导内容步。
6. 存量同步（4.9）：预览 / 冲突处理 / 执行 / 回滚 / 本地覆盖 / 定时预览默认关闭。
7. 优化专项（4.9.1）：i18n 全量校验、错误码 + traceId、空 / 错 / 载态。

## 验收口径

- 功能：上列六块均可在界面闭环，直达越权路由被送往 403，后端二次校验兜底。
- 数据：`V11_30`–`V11_37` 均可正向执行，且 `db/down` 有配对回滚；旧数据按 `case_kind` / `case_code` 回填。
- 幂等：同一导入文件重复预览不新增批次；同一行重复提交落到 UPDATE / UNCHANGED。
- 一致性：`VERSION`、`build-info.properties`、OpenAPI `info.version`、CHANGELOG 四处均为 `4.9.2`。
- 可恢复：同步作业执行后可整单回滚；资产被引用时删除返回 409。

## 不在本版范围

- 真实 DUT、网络损伤与负载压测（无环境，禁止编造数据）。
- 公共库跨实例同步（仅单实例内项目 ↔ 公共库）。
