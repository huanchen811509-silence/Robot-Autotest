## 0. 调研结论摘要

1. 产品已完成一轮新功能迭代（v4.12.0），功能面完整；5.0.X 的收益只能来自**存量路径的缺陷收敛与度量补证**，不是新模块。
2. 本版第一号真实缺陷是**口径冲突**（四项），不是代码缺陷：同一指标在历史日志、契约文件与实跑结果之间存在多个值，若不先冻结，任何「提升」判据都会「怎么改都不红」。
3. 效果类度量**普遍无基线**：Top8 成功率、SUS、长列表 fps、运行链写接口、真实端点评测均为「未测量」。这决定了本版必须「先证明，再优化」。
4. 门禁 32 步已有 31 PASS / 1 FAIL；唯一失败是第 13 步 CDP 浏览器回归，大师已裁定保持取消并如实记录 `FAILS=1`。
5. **新核实的关键约束**：9 支前端体验探针（含 `ux-probe.mjs`、`dark-select-probe.mjs`、`density-probe.mjs`）复用 CDP `:9222` 通道。D1 裁定 CDP 保持取消后，这类探针的**真实浏览器读数在本版不可采集**，只能靠静态机检与离线证据，人工走查项如实 `NOT-RUN`。此约束直接影响 B1 的可判定范围，已同步进测试计划。
