## 3. 功能需求与验收判据

### FR-v2.5-01 退出登录不被服务端阻塞

**要什么**：点退出，本地会话立即失效并跳登录页；服务端撤销是「尽力而为」，失败不影响。

**判据**：
1. 撤销请求**永不 resolve** 时，`performLogout()` 仍在 1s 内完成并 `router.replace('/login')`；
2. 撤销请求抛错时不向调用方抛；
3. 跳转发生时 `localStorage` 里已无 token。

### FR-v2.5-02 菜单文字常驻（折叠态归位）

**要什么**：老用户升级后侧栏默认展开、导航项带文字；折叠是用户显式动作的结果，不是历史遗留。

**判据**：
1. 一次性迁移键 `robot.layout.side.v23` 不存在且旧键为 `true` → 读出 `false` 并把旧键写回 `false`；
2. 迁移键已存在 → 严格按旧键读，**不二次覆盖**用户当前选择；
3. 每个导航项渲染非空文字，且 `title` 与文字一致（窄轨下靠 tooltip 辨认）。

### FR-v2.5-03 窄屏与顶栏不溢出

**要什么**：窄屏收窄轨时文字随图标一起消失（不是被裁掉）；顶栏内容不足时换行，不把最右按钮推出视口。

**判据**：
1. `≤760px` 时 `grid-template-columns` 为 `56px minmax(0, 1fr)`，且 `.app-brand` 与导航项文字 `display: none`；
2. `.app-header` / `.app-header-right` 为 `flex-wrap: wrap`；
3. 新增 px 全部命中 `tools/px-allow.txt` 白名单（`check_tokens` 机检）。

### FR-v2.5-04 一级菜单改名

**要什么**：`用例` → `测试用例`，`资产` → `测试资产`。

**判据**：中英语言包同时改；i18n 键集两语言相等、无同值漏译；路由与能力键不变。

### FR-v2.5-05 版本动态化

**要什么**：版本号有唯一真源；运行期可覆盖；关于页能自己刷出来。

**判据**：
1. 仓库根 `VERSION` 文件存在且为唯一真源，`gen_build_info.py` 优先级为 `APP_VERSION` env > `VERSION` 文件 > pom；
2. `build-info` 响应含 `version` 与 `versionSource`（`env` / `file` / `pom`）；
3. 后端读 `APP_VERSION` / `PLATFORM_VERSION` 环境变量覆盖（重启生效）；
4. 关于页 30s 自动刷新，且仅在 `document.visibilityState === 'visible'` 时刷。

### FR-v2.5-06 AI 助手目录与列表

**要什么**：设置页看到 7 条候选，每条显示安装态、是否可注入、已存密钥掩码、当前端点与模型。

**判据**：
1. `GET /api/ai/assistants` 返回 7 条，`cli_key` 与候选清单完全一致；
2. 每条含 `installed` / `injectable` / `hasKey` / `keyMasked` / `baseUrl` / `model`；
3. 不可注入的条目（如 hermes）显式标 `injectable=false`，前端禁用输入并提示「仅记录」。

### FR-v2.5-07 凭据加密与掩码

**要什么**：密钥只以密文入库；接口只回掩码；明文永不回显、落库、进日志。

**判据**：
1. 库内 `api_key_enc` 为 AES-256-GCM 密文（长度 > 明文，非明文子串）；
2. 接口 `keyMasked` 必须以 `****` 开头，且**不含**明文任何前缀片段；
3. 保存时留空 = 不改（走不写密钥列的 upsert）；`clearKey=true` 才清空。

### FR-v2.5-08 配置真注入子进程

**要什么**：保存的端点 / 密钥 / 模型要真的进到 CLI 子进程，不是只存在库里。

**判据**：
1. `envFor(cli)` 返回该 CLI 需要的全部凭据变量（pi 为 `OPENAI_API_KEY` + `ARK_API_KEY` + `OPENAI_BASE_URL`）；
2. `modelArgs(cli)` 在未配置模型时返回空列表（严格等于原 argv 模板）；
3. 「测试连接」响应含 `appliedEnv`（变量名列表）与 `appliedArgs`，且对真实 CLI 返回 `ok=true`。

### FR-v2.5-09 仅管理员可访问

**要什么**：AI 助手配置是管理员能力，普通角色不可读、不可写、不可测。

**判据**：`GET/PUT/POST` 三个接口对 engineer 角色一律 403，且响应文案说明原因。

### FR-v2.5-10 库结构合规

**要什么**：新表满足审计四列、单列 id 主键、`datetime(3)`、utf8mb4 四条硬口径。

**判据**：`scripts/db-audit.sh` 七项全 OK，其中业务表数 = 71、缺审计四列 = 0、非 `datetime(3)` = 0。

### FR-v2.5-11 文档与关于页同步

**要什么**：README、CHANGELOG、关于页说明、交接文档与实测一致。

**判据**：
1. `CHANGELOG.md` 新增 v2.5 段且四类（新增/变更/修复/破坏性变更）齐全，`<!-- current -->` 锚点在 v2.5；
2. README 的能力行、迁移数、表数、门禁步数与实测一致；
3. 关于页含软件说明与版本来源标识；
4. `check_release_docs` / `check_md_tables` / `check_wbs_consistency` 均不因本版变红。
