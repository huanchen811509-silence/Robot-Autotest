# v2.5 AI 助手配置与体验修复 · ② 评估报告

**文档编号** RA-REL-2026-025-A ｜ **版本** v2.5-ai-config ｜ **批次** B13（待落号） ｜ **门禁** G12（未判）
**日期** 2026-11-08 ｜ **结论** 值得做：7 项全部属「已存在的能力修不好用」或「已有能力缺一个入口」，
无新架构面；但有 3 项硬前置必须先解，否则做了也不算完。

---

## 1. 做不做

| 诉求 | 值不值 | 理由 | 判据 |
|---|---|---|---|
| 退出按钮 | **必做** | 唯一退出入口，失效等于用户被锁在里面，只能清缓存 | 撤销请求永不 resolve 时仍能跳登录页 |
| 菜单文字 | **必做** | 导航不可读等于功能不可达；且坏区间是 1000~1200px 常见笔宽 | 折叠态迁移后默认展开；窄轨下文字与图标二选一，不留「看不见但还在」 |
| 菜单改名 | **必做** | 一行文案，口径统一成本极低 | 中英一致、i18n 键集不变 |
| 版本动态化 | **做** | 版本号是构建期常量，改一次要重打包，与「关于页说明软件」的目的相悖 | 有 `VERSION` 真源 + 运行期覆盖 + 前端能自刷新 |
| AI 助手配置 | **做，且是本版主件** | 7 条候选已在代码里，但没有配置入口 = 用户能看见名字、改不了任何东西 | 端点 / 模型 / 密钥三类可配，且配置**真注入子进程** |
| README / 关于 / 交接文档 | **做** | 上一条新增了表、接口、页面，不同步文档等于交付一半 | 文档读数与实测一致，机检全绿 |

**不做的事（明确划出去）**：

1. **不做多租户级 AI 配置**。v2.5 是全局单份配置（每个 CLI 一行），不做「按项目 / 按用户」分层。
   理由：分层要先定义「哪层覆盖哪层」，需 ADR；本版先让配置能改、能测通。
2. **不做凭据托管服务的接入**（Vault / KMS）。沿用既有 `SecretCipher` + `CRED_MASTER_KEY`，
   换密钥管理方案属另一件事。
3. **不做前端候选顺序可视化调整**。系统提示词要求候选必须完整，顺序属实现细节，不开放给用户。
4. **不做浏览器级像素走查**。本机 Chrome CDP `:9222` 被大师取消且不许重启，
   窄屏视觉类判据本轮**只能记未验**，不得用「代码看起来对」替代。
5. **不推进任何门禁判定**。G12 不申请、不判定；G4 / G5 / G8 / G9 / G10 / G11 状态不变。

## 3. 方案取舍

| 方案 | 取舍 |
|---|---|
| 配置塞进 `system_setting`（k/v） | **弃**。k/v 无结构，且导出 / 审计摘要会把整表带出去，密钥不能进 |
| 每个 CLI 一行单表（`ai_assistant_config`） | **取**。有结构（base_url / model / enabled），可按行审计，密钥独立列加密 |
| 改 `V11_14` 补审计四列 | **弃**。已记为 success，改校验和会直接失败 |
| 追加 `V11_15` 只补列 | **取**。历史脚本只读，与 V11_10..13 顺延落号同一处理方式 |
| 「测试连接」走常规 `FEATURE_AI_REAL_CLI` 闸门 | **弃**。管理员点测试就是明确要求，闸门只会让按钮永远返回降级 |
| `executeAdminTest` 旁路闸门 + 写审计 | **取**。既满足「真跑」，又留痕 |

## 4. 风险

| 风险 | 处置 |
|---|---|
| 密钥轮换后旧密文解不开 → 整页 500 | `decryptQuietly()` 降级为 `keyUnreadable=true`，页面照常渲染并提示重填 |
| 「保存时不填密钥」把已有密钥抹掉 | 空值 = 不改（走 `UPSERT_WITHOUT_KEY`）；只有显式 `clearKey=true` 才清空 |
| 配置注入把不支持的变量塞给 CLI | 目录里 `credentialEnv` 为空的条目标 `injectable=false`，前端禁用输入并明示「仅记录」 |
| 新断点 760px 与白名单冲突 | 只用白名单已有档位，`check_tokens` 机检兜底 |
| 顶栏改 wrap 后高度变化影响栅格 | 复用已有 28px 档位，`check_tokens` + `check_css_vars` 双检 |
