# v4.3.0 需求调研（RA-RES-430）

**文档编号** RA-RES-430 ｜ **版本** v1.0 ｜ **日期** 2026-11-10 ｜ **对应计划** `docs/plan/项目创建菜单与测试资产获取-评估与设计-20261110.md`

> 本版回答两个现场问题：①「新建项目」在侧栏没有独立、可预期的入口，且项目经理（PM）建不了项目；
> ②测试资产（设备 / 网卡 / 接口 / 链路）已有数据，但没有一处能直接读到「谁连到谁」的连接与拓扑。
> 调研只记起点与缺口，不写方案。

## 2. 缺口拆解

| 编号 | 缺口 | 现场表现 | 影响 |
|---|---|---|---|
| G1 | 无「新建项目」侧栏叶子 | 只能从账户菜单或设置页绕进去，路径与语义都对不上 | 用户找不到入口；叶子缺失使导航组语义不完整 |
| G2 | PM 无建项目权限 | 菜单可见但提交 403，属「可见即失败」 | 现场交付由 PM 主导建项目，直接阻塞 |
| G3 | 端口无网卡归属 | 连接只能到「设备-接口」，说不出经过哪块网卡 | 多网卡设备（如 4×200G RoCE）连不起来 |
| G4 | 无连接 / 拓扑读取接口 | 每次要在前端拼装多个 CRUD 结果 | 页面各自实现，口径不一，且无缓存 |
| G5 | 无失效机制 | 资产改了页面还是旧值，或每次全量重算 | 一致性与性能两头都不满足 |
| G6 | 别名只在项目资产页可见 | 引用平台资产后连接仍显示原名 | 跨项目引用读不出本项目叫法 |

## 3. 影响验收的环境事实 [已核实]

| 事实 | 影响 | 应对 |
|---|---|---|
| 门禁 `06-lint` / `13-browser_regression` 在基线即红 | 不能把「基线红」当成本版引入的问题，也不能声称 `FAILS=0` | `EW43-00` 留存基线日志；收尾复跑并与基线逐项对照 |
| WSL 9P 构建比原生慢约 35 倍 | 构建 / 测试只在 WSL 权威副本执行 | 编辑在 Windows，构建测试在 `~/robot-autotest` |
| 无第二个空实例 | 多项目对照只能用同实例内 `P-A` / `P-B` | 记 `[已核实]` 边界，不声称跨实例 |
| 无受控压力环境 | 性能读数只能本机 20 次采样 | `TC-v4.3-38` 写清采样口径，不引用外部基线 |

## 4. 调研结论

1. **两个问题各自独立，可同版收口**：入口与权限属「导航 + 矩阵」改动，连接与拓扑属「派生读模型」改动，互不依赖 API 形状。
2. **网卡必须是端口的属性，不是新实体**：用户明确纠正过「设备→网卡→接口」是连接路径，不新增网卡实体表、不建焊接 / 线缆字段。
3. **复用窗口是 12 小时而不是 300 秒**：用户明确要求默认 `43200s` 且可配置，并叠加「资产变更立即失效」与手工刷新两条兜底。
4. **判不了就写判不了**：无跨实例、无压力环境的部分逐条记 `NOT-RUN` / 写清采样口径，不用本机读数冒充集群数据。
5. **不做的事**见 [01-ASSESSMENT.md](./01-ASSESSMENT.md) §4。
