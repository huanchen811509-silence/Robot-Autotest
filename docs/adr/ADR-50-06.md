# ADR-50-06 · 门禁只增不删，按 D1 如实记录 FAILS=1

| 项 | 内容 |
|---|---|
| 状态 | 已裁定（D1~D9 大师 11:09 拍板后生效） |
| 日期 | 2026-11-12（GMT+8） |
| 归属 | 5.0.X 存量功能优化打磨 |

## 1. 背景
第 13 步 CDP 按大师令保持取消；删步或降判据会制造「全绿」假象。

## 2. 决策
原 32 步名称、顺序、判据不动；新增 33~36 步；原 32 步汇总如实 `FAILS=1`，新增 4 步 `FAILS=0`，两份日志分开归档。

## 3. 备选方案
临时跳过第 13 步；把 36 步合成一个 `FAILS=0` 结论。

## 4. 后果
读数可信；代价是门禁永远不会显示全绿。

## 5. 复核方式
`gates.sh` 的 `GATES_RESULT` 与 `raw/` 下两份汇总日志。
