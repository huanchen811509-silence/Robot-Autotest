# ADR-35-03 · 门禁分层与汇总同批次治理

| 项 | 内容 |
|---|---|
| 状态 | 已采纳 |
| 日期 | 2026-11-09 |
| 约束范围 | v3.5.0 起全仓（D1–D9 已由大师 2026-11-09 10:10 授权） |
| 依据 | 《v3.5+ 开发与测试计划》RA-DTP-35-001 v1.1 §2.2 |

## 背景

`scripts/gates.sh` 已 27 步，但 `00-full-run.log` 停在 11-08 12:06 的 19 步 `FAILS=2`；分步日志与汇总冲突

## 决策

分快速门 / 重门 / 发版门三层，不重排步骤编号；新增步骤先 `--selfcheck` 负向实证；一次全量跑产出与分步日志同批次汇总

## 后果与护栏

分步日志 PASS 不等于 27 步全绿；旧汇总标历史读数且注明 CDP 状态变化；发版门归大师

## 验证方式

见 RA-DTP-35-001 §3 对应工作包与 `docs/evidence/v3.5.0/` 证据目录；本 ADR 的护栏纳入 `REG-*` 回归与门禁判据。
