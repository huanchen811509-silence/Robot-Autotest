# ADR-39-05 · 页大小固定四档 + 本地记忆，不做自由输入

| 项 | 内容 |
|---|---|
| 状态 | 已采纳 |
| 日期 | 2026-11-09 |
| 约束范围 | v3.9.0 起全部列表页；与 ADR-3X-04（服务端分页上限 100）配合 |
| 依据 | RA-PRD-39-001 §3 ADR-39-05；`useListPageSize` |

## 背景

列表页分页器以下大面积空白（实测 `/cases` 337px、`/runs` 231px），用户要点下一页才能看到同屏本可容纳的行。根因是行数固定 10、且不随视口高度自适应。

## 决策

- 四档固定页大小：10 / 20 / 50 / 100；默认值按视口高度估算（每行 ~44px，留出顶栏、页头、分页条与留白 ≈ 302px），估算结果向上取到最近档位。
- 选择结果写 `localStorage`，跨页、跨会话记忆；非法值回落默认档。
- **明确不做**：不做「自由输入每页条数」。

## 后果与护栏

- 正面：语义确定，用户不会遇到「每页 37 条」这种既难解释也难对齐后端的档位。
- 负面：极端窄屏下默认估算值可能偏保守，需要用户手动调档；100 档与 ADR-3X-04 的单页上限对齐，不与后端打架。
- 护栏：`useListPageSize.spec` 覆盖四档、记忆、非法值回落；`scripts/density-probe.mjs` 判「分页条以下空白 ≤ 120px」。
- 复核条件：后端放开单页上限或引入虚拟滚动时，本 ADR 需重新评估。

## 验证方式

`TC-v3.9-14`（`/cases` 36px、`/runs` 36px、`/assets` 0px）、`TC-v3.9-15`（11 条单测）。
