# ADR-50-05 · 实验室与现场数据严格分离

| 项 | 内容 |
|---|---|
| 状态 | 已裁定（D1~D9 大师 11:09 拍板后生效） |
| 日期 | 2026-11-12（GMT+8） |
| 归属 | 5.0.X 存量功能优化打磨 |

## 1. 背景
本机 CDP、离线契约、fake CLI 与真实用户 / 真实端点 / 真机不是同一证据等级。

## 2. 决策
所有 CWV 证据带 `mode: lab` 或 `mode: field` 字段；lab 数据不得写进「达标」结论。

## 3. 备选方案
统一用本机探针代表全部分布。

## 4. 后果
避免把冒烟测试当真实用户 p75；代价是 field 类结论本版缺失。

## 5. 复核方式
`tools/check_v50_mode.py` 扫证据字段；`TC-v5.0-28` 复核。
