# ADR-39-07 · 预置报告模板强制保留必填项，预置不等于绕过门禁

| 项 | 内容 |
|---|---|
| 状态 | 已采纳 |
| 日期 | 2026-11-09 |
| 约束范围 | v3.9.0 起报告字段模板（21 字段 / 4 卡 / 4 预置） |
| 依据 | RA-PRD-39-001 §3 ADR-39-07；`ReportTemplatesView` |

## 背景

报告字段从散落的复选框收成 4 张卡后，用户很容易「全都不选」交出一份没有结论、没有项目名的报告。预置模板的初衷是省事，不是把合规字段也省掉。

## 决策

21 个字段里有 6 类（身份 / 结论统计 / 环境 / 合规）中的**必填项锁定**：不可关闭、不可通过预置模板绕过。预置模板（简版 / 标准 / 完整 / 审计）只决定**非必填项**的默认勾选。

## 后果与护栏

- 正面：任何模板产出的报告都至少含「谁、何时、什么版本、结论是什么」，对外可用。
- 负面：想产出极简报告时仍要带必填项，牺牲一点灵活性。
- 护栏：`lockedFields` 由后端下发的模板元数据决定，前端只渲染禁用态；`ReportTemplatesView.spec` 断言锁定字段无开关；真实探针断言 `lockedFields` 数量与 `fieldCount` 一致。
- 复核条件：出现「对外报告字段口径」变更（新增法定字段）时，先改 PRD 再模板。

## 验证方式

`TC-v3.9-16`（`fieldCount=21` / `cardCount=4` / `presetCount=4` / `lockedFields=21`）、`TC-v3.9-17`（模板页 0.94 屏）。
