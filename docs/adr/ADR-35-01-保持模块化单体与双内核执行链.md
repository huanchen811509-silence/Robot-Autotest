# ADR-35-01 · 保持模块化单体与双内核执行链

| 项 | 内容 |
|---|---|
| 状态 | 已采纳 |
| 日期 | 2026-11-09 |
| 约束范围 | v3.5.0 起全仓（D1–D9 已由大师 2026-11-09 10:10 授权） |
| 依据 | 《v3.5+ 开发与测试计划》RA-DTP-35-001 v1.1 §2.2 |

## 背景

68 Controller / 345 路由注解 / 87 表 / 57 迁移；单主机 `:8001` + `:8081` 部署形态

## 决策

不做微服务化与分布式重写；双内核 SPI、执行链幂等键、`run.kernel` 快照与四条冻结契约不变

## 后果与护栏

ArchUnit R1–R8 守分层；不引入 Redis / MQ / 独立搜索集群 / 外部 APM；新增组件须另立 ADR

## 验证方式

见 RA-DTP-35-001 §3 对应工作包与 `docs/evidence/v3.5.0/` 证据目录；本 ADR 的护栏纳入 `REG-*` 回归与门禁判据。
