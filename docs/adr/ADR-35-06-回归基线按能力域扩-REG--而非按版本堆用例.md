# ADR-35-06 · 回归基线按能力域扩 REG-* 而非按版本堆用例

| 项 | 内容 |
|---|---|
| 状态 | 已采纳 |
| 日期 | 2026-11-09 |
| 约束范围 | v3.5.0 起全仓（D1–D9 已由大师 2026-11-09 10:10 授权） |
| 依据 | 《v3.5+ 开发与测试计划》RA-DTP-35-001 v1.1 §2.2 |

## 背景

v3.1–v3.4 新增搜索 / 视图 / 通知 / 缓存 / 契约 / 流式 / 证据问答 / 归档 / 准入 / 安全头 / SLO 共 11 类尚无回归固化

## 决策

每类至少 1 条真实链路回归，进 CI 且可单跑；负向注入证明「删能力必红」

## 后果与护栏

不许改断言迁就实现；不稳定用例进 `flaky-ledger.md` 隔离而非删除

## 验证方式

见 RA-DTP-35-001 §3 对应工作包与 `docs/evidence/v3.5.0/` 证据目录；本 ADR 的护栏纳入 `REG-*` 回归与门禁判据。
