# ADR-35-10 · 安全按 OWASP ASVS 与 LLM Top 10（2025）逐条自评

|---|---|
| 状态 | 已采纳 |
| 日期 | 2026-11-09 |

## 背景

AI 风险主要在应用层；门禁 25 步 `high=0 medium=1` 仍有浮动依赖未收口

## 决策

逐条自评 + 提示注入 / 过度代理 / 无界消耗专项用例；依赖 SCA 高危 0；密钥轮换演练

## 后果与护栏

最小权限 + 人工审批；日志 / 提示词 / 报告无明文；逐条校验 `keyMasked` 前缀而非整段查 `sk-`

## 验证方式

见 RA-DTP-35-001 §3 对应工作包与 `docs/evidence/v3.5.0/` 证据目录；本 ADR 的护栏纳入 `REG-*` 回归与门禁判据。
