# ADR-50-07 · 新增能力默认关闭、可查询、可一键回退

| 项 | 内容 |
|---|---|
| 状态 | 已裁定（D1~D9 大师 11:09 拍板后生效） |
| 日期 | 2026-11-12（GMT+8） |
| 归属 | 5.0.X 存量功能优化打磨 |

## 1. 背景
D5 / D6 裁定本版不启用 RUM、告警通知、隔离演练与真实端点评测。

## 2. 决策
`FEATURE-FLAGS.md` 登记三个本版能力开关且恒为 `false`；机检类检查常开，不属灰度能力。

## 3. 备选方案
直接上线再观察；把机检也做成可关开关。

## 4. 后果
灰度与回退可控；代价是本版不采集真实用户数据。

## 5. 复核方式
`tools/check_v50_flags.py` 校验登记与默认值。
