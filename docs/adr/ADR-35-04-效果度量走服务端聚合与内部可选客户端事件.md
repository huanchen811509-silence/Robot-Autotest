# ADR-35-04 · 效果度量走服务端聚合与内部可选客户端事件

| 项 | 内容 |
|---|---|
| 状态 | 已采纳 |
| 日期 | 2026-11-09 |
| 约束范围 | v3.5.0 起全仓（D1–D9 已由大师 2026-11-09 10:10 授权） |
| 依据 | 《v3.5+ 开发与测试计划》RA-DTP-35-001 v1.1 §2.2 |

## 背景

Top 8 成功率 / 耗时、SUS、50 查询集、CWV、采纳率均无证据；埋点存在隐私与性能风险

## 决策

事件字典冻结最小字段；服务端聚合优先；客户端事件仅内部评估期开启，默认关闭、可关闭

## 后果与护栏

不采凭据 / 令牌 / 用例正文 / 实网配置 / 设备口令；事件字典过隐私核对；无数据显示「未测量」而非 0

## 验证方式

见 RA-DTP-35-001 §3 对应工作包与 `docs/evidence/v3.5.0/` 证据目录；本 ADR 的护栏纳入 `REG-*` 回归与门禁判据。
