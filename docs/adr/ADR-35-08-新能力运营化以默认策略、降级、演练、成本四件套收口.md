# ADR-35-08 · 新能力运营化以默认策略、降级、演练、成本四件套收口

| 项 | 内容 |
|---|---|
| 状态 | 已采纳 |
| 日期 | 2026-11-09 |
| 约束范围 | v3.5.0 起全仓（D1–D9 已由大师 2026-11-09 10:10 授权） |
| 依据 | 《v3.5+ 开发与测试计划》RA-DTP-35-001 v1.1 §2.2 |

## 背景

归档 / 准入 409 / AI 配额 / 告警与 SLO 已上线但缺默认值说明与故障演练

## 决策

四类能力各出默认值、开关、降级路径与成本视图；8 个运行手册场景可执行并留演练记录

## 后果与护栏

归档 `enabled=false` 不擅自开启；不移动生产数据；注入演练须证明「不注入不红、注入必红」

## 验证方式

见 RA-DTP-35-001 §3 对应工作包与 `docs/evidence/v3.5.0/` 证据目录；本 ADR 的护栏纳入 `REG-*` 回归与门禁判据。
