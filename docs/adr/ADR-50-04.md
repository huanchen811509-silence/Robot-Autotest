# ADR-50-04 · 效果度量先建基线再谈提升，埋点默认关闭

| 项 | 内容 |
|---|---|
| 状态 | 已裁定（D1~D9 大师 11:09 拍板后生效） |
| 日期 | 2026-11-12（GMT+8） |
| 归属 | 5.0.X 存量功能优化打磨 |

## 1. 背景
Top8 成功率、SUS、长列表 fps、运行链、真实端点评测均「未测量」，没有前后对照就无法判定「提升」。

## 2. 决策
B0 产出带 `未测量` 显式字段的基线 JSON；无基线的目标如实判 `PARTIAL`，禁止填 0 或估算。

## 3. 备选方案
先改 UI 再补测；用实验室 CDP 读数折算真实用户达标。

## 4. 后果
结论可判定；代价是本版不产出真实体验提升的量化结论。

## 5. 复核方式
`tools/check_v50_metric_schema.py` 守护未测量字段不被填数。
