# ADR-35-02 · 基线固化采用 WSL 权威副本收口再同步双远程

| 项 | 内容 |
|---|---|
| 状态 | 已采纳 |

| 约束范围 | v3.5.0 起全仓（D1–D9 已由大师 2026-11-09 10:10 授权） |
| 依据 | 《v3.5+ 开发与测试计划》RA-DTP-35-001 v1.1 §2.2 |

## 背景

v3.1–v3.4 实现在两仓均未入库；WSL 2765 项为 `100644→100755` 模式位噪声；9P 上 push 会卡死

## 决策

WSL 设 `core.fileMode=false` / `core.autocrlf=input` 后一次性暂存提交；`git push origin main` + `git push github main`；E 盘用 bundle 快进到同一 sha

## 后果与护栏

三处 sha 一致才算完成；提交前核对暂存清单 0 个 mode change；E 盘快进前 stash 留现场

## 验证方式

见 RA-DTP-35-001 §3 对应工作包与 `docs/evidence/v3.5.0/` 证据目录；本 ADR 的护栏纳入 `REG-*` 回归与门禁判据。
