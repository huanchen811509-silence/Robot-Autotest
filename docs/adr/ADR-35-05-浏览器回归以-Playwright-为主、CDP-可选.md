# ADR-35-05 · 浏览器回归以 Playwright 为主、CDP 可选

| 项 | 内容 |
|---|---|
| 状态 | 已采纳 |
| 日期 | 2026-11-09 |
| 约束范围 | v3.5.0 起全仓（D1–D9 已由大师 2026-11-09 10:10 授权） |
| 依据 | 《v3.5+ 开发与测试计划》RA-DTP-35-001 v1.1 §2.2 |

## 背景

13 步曾因 `:9222` CDP 单点不可用导致 FAILS；11-09 00:05 日志显示恢复（48 项 0 失败）

## 决策

以现有可用通道做 Playwright 为主的多浏览器能力，CDP 降为可选；截图与 trace 入证据

## 后果与护栏

**不重启大师已取消的后台任务**；不得因某次分步 PASS 宣称通道永久可用

## 验证方式

见 RA-DTP-35-001 §3 对应工作包与 `docs/evidence/v3.5.0/` 证据目录；本 ADR 的护栏纳入 `REG-*` 回归与门禁判据。
