# ADR-50-01 · 5.0 补丁线：v5.0.0 唯一落号，B0~B4 为批次

| 项 | 内容 |
|---|---|
| 状态 | 已裁定（D1~D9 大师 11:09 拍板后生效） |
| 日期 | 2026-11-12（GMT+8） |
| 归属 | 5.0.X 存量功能优化打磨 |

## 1. 背景
本版是存量打磨，收益来自缺陷收敛与度量补证，不需要多个 minor 版本各自开六件套。

## 2. 决策
以 `v5.0.0` 为唯一落号版本，`5.0.1` / `5.0.2` 只收修复；B0~B4 是同一版本内的批次，共用一套 `FR-v5.0-xx` / `TC-v5.0-xx` / `W50-xx` 编号。

## 3. 备选方案
5.X 多 minor 系列（每版独立六件套）；单版不分波次。

## 4. 后果
一套编号空间，评审与追溯成本最低；代价是所有批次共用一个准出判据。

## 5. 复核方式
`tools/check_v50_trace.py` 校验 30 FR / 42 TC / 30 WBS 连续。
