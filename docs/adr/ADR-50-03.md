# ADR-50-03 · 零新增表、零破坏性 API、双内核执行链零改动

| 项 | 内容 |
|---|---|
| 状态 | 已裁定（D1~D9 大师 11:09 拍板后生效） |
| 日期 | 2026-11-12（GMT+8） |
| 归属 | 5.0.X 存量功能优化打磨 |

## 1. 背景
436 个路由注解与 RF / pytest 双内核契约是本产品最稳的部分，改动的回归面远大于打磨收益。

## 2. 决策
所有改动限定在文档、机检脚本、静态样式与只读证据；数据库零新增表列，执行链以 sha256 清单守门。

## 3. 备选方案
借优化期重构分层或统一状态层。

## 4. 后果
回归面可控；代价是结构类诉求全部退出本版。

## 5. 复核方式
`tools/check_v50_boundary.py` 校验 `docs/evidence/v5.0.0/baseline/exec-chain.sha256` 零改动。
