# ADR-50-02 · 口径冲突以「裁决清单 + 单一真源」解决

| 项 | 内容 |
|---|---|
| 状态 | 已裁定（D1~D9 大师 11:09 拍板后生效） |
| 日期 | 2026-11-12（GMT+8） |
| 归属 | 5.0.X 存量功能优化打磨 |

## 1. 背景
同一指标在历史日志、契约文件与实跑结果之间存在多个真实读数，直接取最新值会让历史证据失去解释。

## 2. 决策
B0 用命令实测给出裁决值，落 `docs/plan/v5.0-口径裁决清单.md`；其余读数标库名与时点，不静默改写。

## 3. 备选方案
直接取最新值；把所有历史数统一改成同一个数。

## 4. 后果
历史证据不被篡改；代价是引用任何数字都要标口径。

## 5. 复核方式
`raw/caliber-probe.log` 留命令与原始输出；`README.md` 两处过时读数按内容匹配回写。
