# ADR-35-09 · 变更管理引入特性开关与发布记录，DORA 只建读数不设考核

| 项 | 内容 |
|---|---|
| 状态 | 已采纳 |
| 日期 | 2026-11-09 |
| 约束范围 | v3.5.0 起全仓（D1–D9 已由大师 2026-11-09 10:10 授权） |
| 依据 | 《v3.5+ 开发与测试计划》RA-DTP-35-001 v1.1 §2.2 |

## 背景

缺部署频率 / 前置时间 / 变更失败率 / 恢复时间读数；指标驱动易诱发作假

## 决策

小批次、可回退、发布与部署解耦；发布记录含版本戳与回滚点；DORA 五项只建立读数

## 后果与护栏

KPI 与门禁检查项不在可下调范围；不因指标好看而合并批次或跳过回归

## 验证方式

见 RA-DTP-35-001 §3 对应工作包与 `docs/evidence/v3.5.0/` 证据目录；本 ADR 的护栏纳入 `REG-*` 回归与门禁判据。
