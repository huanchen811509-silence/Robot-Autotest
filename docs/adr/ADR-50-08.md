# ADR-50-08 · 证据一律落 docs/evidence/v5.0.0/ 入库路径

| 项 | 内容 |
|---|---|
| 状态 | 已裁定（D1~D9 大师 11:09 拍板后生效） |
| 日期 | 2026-11-12（GMT+8） |
| 归属 | 5.0.X 存量功能优化打磨 |

## 1. 背景
`docs/evidence/gates/logs/` 被 `.gitignore` 忽略，报告引用它会导致 clone 后不可复核。

## 2. 决策
本版门禁汇总、取证命令、基线、压测报告均落 `docs/evidence/v5.0.0/`；报告内不得引用被忽略目录。

## 3. 备选方案
沿用历史 `gates/logs/` 路径。

## 4. 后果
clone 后可复核；代价是需归档一次基线日志。

## 5. 复核方式
`tools/check_v50_evidence.py` 校验路径与 `git check-ignore`。
